# 普通人2026做自媒体：Codex+HyperFrames+Remotion 一键出片完全手册

有人已经在用这套工具在抖音月入三五万。

不是噱头。这几天 X 上有人把完整工作流开源出来了，用 Codex 做视频，日产 30 条，效率是以前的五倍。

这篇文章告诉你这三个工具是什么，具体怎么用，以及你现在可以从哪一步开始。

## 先说清楚三个工具是干什么的

**Codex（或 Claude Code）**

你的 AI 程序员。

你用中文说「帮我做一个 90 秒的知识视频，讲时间管理，放抖音」，它会自己装环境、写代码、生成配音、渲染出 MP4 交给你。

你不需要会编程。你只需要会打字。

两款工具性质相同，Codex 是 OpenAI 出品（内置在 ChatGPT Pro，订阅 $20/月），Claude Code 是 Anthropic 出品（收费方式类似）。本文的流程对两款都适用。

**Remotion**

把代码变成视频的框架。你不用直接操作它，Codex 会帮你操作。

它的核心价值是：视频变成了代码文件，可以像改文档一样修改——改一行文案、换一张图、调一种配色，都是几秒的事，不用重新剪辑。

做过一套模板以后，批量出片很快。适合需要稳定产出的账号。

**HyperFrames**

把 HTML 网页变成视频。

如果你想做图文动效类视频——讲书评、数据卡片、知识科普——HyperFrames 更直接。视觉效果偏「高级知识类」，和很多你刷到的书评号、深度内容号风格接近。

## 三种做法，三种内容

这套工具不是一个方案，而是三条路，对应三类内容。

### 路线一：讲书号 / 知识卡片

先说真实情况：目前抖音和视频号上，做讲书号赚到钱的人，用的工具链大多是 DeepSeek 写文案 + 剪映出视频，不是 Codex + HyperFrames。

真实数据：
- 视频号书单号，22 天橱窗跟买 8612 人次，佣金 6.4 万元（书目《百年孤独》，佣金约 30%）
- 抖音读书账号，20 天涨粉 11 万，单篇最高点赞 14 万，月橱窗收入 1 万+

这两个案例都是用 DeepSeek/剪映做的，不是 Codex。讲书号本质上是内容 + 选题的生意，工具越简单越好，剪映对普通人更友好。

那 HyperFrames 能做讲书号吗？可以，但没什么额外优势。你给它书名和 5 个核心观点，它做出来的视频是：深色背景、标题动效入场、每段文字逐字出现。和剪映做出来的效果差不多，但折腾成本高得多。

变现方式：抖音/视频号橱窗挂书链，佣金 10%-50%（图书品类佣金率高，但单价低）。0 粉丝也能开通视频号橱窗。

版权：总结书的核心观点没问题。大段朗读原文算侵权，被投诉会下架。

### 路线二：带货视频 / 混剪（Codex + FFmpeg + Python）

核心逻辑是复刻爆款。找一个抖音爆款，用 FFmpeg 拆分成逐镜头的关键帧，然后让 Codex 从你自己的素材库里找视觉相似的素材，自动配音、生成字幕，最后输出剪映草稿，直接打开微调就能发。

这条路线不用 HyperFrames 和 Remotion，用的是 FFmpeg + Python + 豆包语音 API（配音 4-8 毛/条）。

门槛：你要有自己的素材库，能跑通 Python 环境。做过电商内容、想扩大产量的人，这条路产量最高。

### 路线三：数据科普 / 知识图表（Remotion / HyperFrames 真正的优势所在）

适合「全球最贵的 10 个城市」「过去 20 年收入变化」「宇宙有多大？用数字说话」这类内容。

Remotion 的优势是精准控制：数字跳动动画、柱状图从左到右依次出现、高亮某一项——每一帧精确到毫秒，数据换成新的之后直接重渲染，不用重新做。

真实案例：B 站「橙子科技崔子橙」，445 粉丝，靠一条「如果历史人物的一生能展开成地图」获得 87 万播放。典型算法推荐驱动——内容够新奇，不需要粉丝基础。

用数学科普工具 Manim 的「Orthocenter」，靠程序化的几何动画，积累了 37 万粉丝。这类内容，剪映完全做不了，这才是 Remotion/HyperFrames 真正的差异化所在。

这类视频适合发 B 站和视频号。如果做英文内容，数据可视化/历史地图类视频是 YouTube 上播放量最高的科普赛道之一，中文版几乎空白。

三条路对比：
- 变现最快：带货视频（工具门槛最高，但效率提升最明显）
- 门槛最低：讲书号（剪映就能做，不需要折腾 Remotion/HyperFrames）
- 差异化最大：数据科普（剪映做不了，内容稀缺，算法喜欢）

HyperFrames 和 Remotion 真正值得折腾的场景，是数据动画、产品演示、HTML 卡片这类剪映完全做不到的事。

## 最小起步：Codex + Remotion 出第一条视频

这是门槛最低的路线，只需要三类提示词。

### 第一步：搭流水线（只做一次）

打开 Codex（或 Claude Code），新建一个空文件夹，发这段话：

```
帮我用 Remotion + Edge TTS 搭一个"做中文配音视频"的项目。
横屏 1920×1080、视频长度跟着配音走、底部自动字幕、深色背景。
搭好渲染一个最小示例给我看效果。
```

它会自己装 Node.js 依赖、写项目文件、渲染一个样片给你看。你只需要授权它运行安装命令。

这一步大概 10-20 分钟。做完之后你就有了一套可以反复用的视频模板。

### 第二步：每期视频，两步走

第一步：要脚本（先看稿，确认再出片）

```
做一期关于【主题】的视频，面向【受众】，发【平台】，大概【时长】。
拆成 6-8 段，每段写口语化的口播文案 + 画面设计。
先给我看分镜脚本，我确认后再做。
```

为什么先看稿：文案是视频的灵魂。稿子不对，后面什么都白做。

第二步：确认脚本后，要视频

```
按上面的脚本生成配音并渲染成 MP4。
```

十几分钟后，MP4 到你手上。

### 第三步：不满意就说人话

用大白话，一次提一两个改动：
- 「第 3 段太长，精简到一句话」
- 「换个活泼一点的年轻女声」
- 「改成抖音竖屏 1080×1920，重新渲染」
- 「配色改暖色系」

不需要懂参数，描述感觉就行，它自己选具体设置。

## HyperFrames 和 Remotion 具体区别

两个工具经常被放在一起提，但适合的场景不同。

**HyperFrames（HeyGen 出品，2026 年 4 月开源，Apache 2.0 免费）**

用普通 HTML + CSS + GSAP 动画描述画面，通过 Headless Chrome 逐帧截图合成 MP4。

核心优势：AI 会写 HTML，所以 Codex/Claude Code 几乎不用学习就能上手。官方有 21 个 Agent Skill，直接安装：

```
npx skills add heygen-com/hyperframes --all
```

之后让 Codex 写 HTML，用这两条命令预览和渲染：

```
npx hyperframes preview   # 浏览器实时预览
npx hyperframes render    # 输出 MP4
```

B 站上已经有 99+ 相关视频，播放量最高的一条「hyperframes 对比 remotion，vibe 做动画哪家强？」有 27 万播放。

**Remotion（2021 年，成熟工具）**

用 React 组件描述画面，用帧数和时间轴控制动画。优势是组件复用性强，批量渲染方案成熟，适合做品牌栏目、数据可视化、每周固定格式的内容。

缺点是 AI 要先学会 Remotion 的 API 才能上手，生成代码出错率更高一点。Remotion 官方文档已经加了 AI 适配支持，任意文档页加 .md 后缀即可获取 Markdown 格式，Claude Code 可以直接读取。

怎么选：
- 想让 AI 直接生成，越快出片越好 → HyperFrames
- 想做稳定的栏目模板，需要版本管理，长期维护 → Remotion
- 已经有 React 技术背景 → Remotion
- 完全不会编程，纯靠自然语言驱动 → HyperFrames 更顺

## 我自己操作了一遍，这是过程

光说不练是虚的。这篇文章写完的同一天，我用 Claude Code + HyperFrames 做了一条 30 秒竖屏视频，把这套工作流走了一遍。

我是怎么做的，三步：

### 第一步：准备环境（约 20 分钟）

系统默认的 Node 是 v26，HyperFrames 有已知兼容问题，先切 v22：

```
source ~/.nvm/nvm.sh && nvm use 22
```

再切国内 npm 镜像，否则装包很慢：

```
npm config set registry https://registry.npmmirror.com
```

### 第二步：让 Claude Code 写 HTML（约 30 分钟）

新建一个文件夹，打开 Claude Code，把需求说清楚：30 秒、竖屏 1080×1920、深色背景、展示三步工作流、最后一屏放群二维码。

Claude Code 生成了完整的 HTML + GSAP 动画代码，包含 4 个场景：大标题、步骤卡片、数据对比、结尾二维码入场。每个场景的入场动画、进度条、底部署名全部自动写好，我没有改一行代码。

### 第三步：渲染（1 分 39 秒）

```
# render 参数是目录路径，不是文件名；入口文件必须叫 index.html
npx hyperframes render . --output demo-output.mp4
```

900 帧（30fps × 30秒），5 个 worker 并行跑，输出 1.5MB 的 MP4。

踩到的三个坑，提前告诉你：
1. `npx hyperframes render demo.html` 报错 "Not a directory"——HyperFrames 接收目录路径，不接受文件名，改成 `render .`（当前目录）解决。
2. 入口文件必须命名 index.html，叫别的名字找不到，整个项目渲染不起来。
3. 系统默认 Node v26 跑不动，必须手动切到 v22。这三个坑加在一起，浪费了约 40 分钟。

整个流程从零到出片，实际用时几分钟。

## 带货复刻工作流，完整四步

如果你要走带货路线，这是目前最成熟的 Codex 自动化剪辑方案。

### 第一步：拆解参考视频

找一个抖音爆款，下载后发给 Codex：

```
帮我分析这个参考视频：work/reference.mp4
用 FFmpeg 拆分成逐镜头片段，提取每个镜头的关键帧截图，
同时把文案提取出来（用 ASR 转写），
生成 recipe.json，记录每个镜头的时长、场景类型和文案。
```

它自己调用 FFmpeg，完成后你会得到一份镜头结构表。

### 第二步：素材匹配

```
基于 recipe.json，遍历我的素材库 assets/，
给每个素材提取关键帧，按颜色/亮度/构图和参考镜头做相似度匹配，
输出 matches.json。
规则：同一素材不连续用，置信度低于 60% 的标记为「缺素材，需人工补」。
宁可留空，也不要硬凑不搭的素材。
```

### 第三步：配音和字幕

素材确认后，生成配音：

```
读取每段文案，用豆包语音 API 生成配音。
配音实际时长决定对应镜头时长——配音5秒，镜头拉到5秒。
字幕用词级时间戳对齐，不要用字符数估算。
```

### 第四步：出剪映草稿

```
生成剪映草稿文件。
注意：三个 ID（内容ID/元数据ID/根索引ID）必须一致且唯一，
素材路径用绝对路径，文件必须真实存在。
```

第一次生成大概 20-30 分钟。草稿出来后打开剪映检查：时间轴对不对、字幕有没有遮挡、配音和画面有没有同步。没问题就可以发布。

跑顺以后，效率提升五倍——原来一天 6 条，现在 30 条。

关键工具：FFmpeg + Python 3.8+ + 豆包语音 API + 剪映专业版

## 成本和变现

固定成本：
- Codex（ChatGPT Pro）：$20/月
- 配音（豆包语音 API）：4-8 毛/条，1 分钟视频
- 其他工具（FFmpeg、Remotion、HyperFrames）：免费开源

三条路线的变现逻辑不同：

**讲书号（真实数据）**：视频号橱窗 0 粉丝可开通，抖音橱窗保证金 500 元。图书佣金率高，10%-50%，但单价低（一本书 25 元，佣金 7.5 元）。现实预期：做到能出单的阶段，月入几千到一两万比较可期；「月入十万」基本都是卖教程的。

**带货视频**：这条路产量最高，但门槛也最高。跑通工作流之后日产 30 条是真实数字，但前提是你已经有素材库、有在跑的账号。成本降幅是真实的——传统一条视频 2000-5000 元，AI 化之后几十元，周期从 3-5 天到 15 分钟。

**数据科普**：变现最慢，但内容价值最高。B 站 10 万播放的广告收入只有 100-500 元，真正的变现靠品牌合作和课程。起步慢，但做出稀缺内容之后算法会持续推。

最重要的前提：内容要能过推流。平台不推，再高效的批量生产也没用。

## 真实的限制，说清楚

工具负责生产，不负责选题。内容方向对不对、是不是用户想看的，这个工具解决不了。选题判断还是你来。

第一条视频需要时间。环境搭建、模板调试、第一次渲染，预计需要 1-4 小时。跑顺之后才会快。

视频质量需要人工把关。字幕有没有遮挡、配音和画面有没有对齐、脚本文案去没去 AI 味——这些需要你自己看一遍。不能完全无人值守。

**AI 内容标注是法律义务，不是建议。**《人工智能生成合成内容标识管理办法》2025 年 9 月 1 日正式生效，CAC + 工信部 + 公安部 + 广电总局联合颁布。

具体要求：
- 视频开头帧显示不少于 2 秒「AI 生成」字样，且全程持续显示
- 文件里必须嵌入技术水印（元数据）
- 禁止删除或隐藏标识
- 未标注的带货视频被法律定性为虚假宣传，最高罚款 200 万元

2026 年 4 月起「清朗·整治 AI 应用乱象」专项行动已删除违规内容 600 余万条，处置账号 2.6 万个。执法在加速。

好消息是：Remotion 和 HyperFrames 是代码驱动的动态图形渲染，不是扩散模型生成的内容，目前没有被平台 AI 检测系统误判的记录，比用可灵/即梦/Sora 做出来的视频合规成本更低。

小红书：2026 年 6 月升级了 AI 检测，全自动运营账号直接封号。不要指望完全无人值守。

## 你现在可以做的第一件事

一件要先说清楚的事：Codex 是 OpenAI 产品，国内直接访问有限制。Claude Code 是 Anthropic 出品，功能基本一样，国内访问相对稳定。下面的流程用 Claude Code 也完全适用，发给它的提示词完全相同。

两条路，选一条：

### 路线 A：Remotion（稳定，适合长期做内容）

国内用户先做两件事，否则后面会卡住：

```
# 1. 切 npm 镜像，否则安装很慢
npm config set registry https://registry.npmmirror.com

# 2. 确认 Node 版本用 v22，v26 有已知 bug
nvm use 22
```

然后创建项目：

```
npx create-video@latest --hello-world
cd my-video
npm install
npm run dev
```

浏览器自动打开 Remotion Studio 预览界面。

重要：第一次渲染前必须做这一步，否则会卡死。

Remotion 渲染需要下载 Chrome Headless Shell（约 93MB），地址在 Google 服务器，国内直接超时。在项目根目录创建 remotion.config.ts：

```typescript
import { Config } from '@remotion/cli/config';
Config.setBrowserExecutable(
  '/Applications/Google Chrome.app/Contents/MacOS/Google Chrome'
  // Windows 通常是 'C:\\Program Files\\Google\\Chrome\\Application\\chrome.exe'
);
```

然后打开 Claude Code，安装 Remotion 知识包（不装会犯 Remotion 特有的错误）：

```
npx skills add remotion-dev/skills
```

再发这句话：

```
我已经有一个 Remotion 项目，路径是 [你的项目路径]。
帮我做一个 60 秒的中文知识视频，主题是[你选一个，比如：「时间管理的3个误区」]，
面向抖音/视频号竖屏（1080×1920），加配音、底部自动字幕、深色背景。
先给我一个 6 段分镜脚本，每段 10 秒，我确认后再用 npx remotion still 渲染单帧验证。
```

配音：Edge TTS 是 Python 工具（pip install edge-tts），免费，中文语音用 zh-CN-XiaoxiaoNeural。想要更精准字幕对齐，用 MiniMax TTS API，国内直连，有字符级时间戳。

### 路线 B：HyperFrames（更快出片，AI 更容易驾驭）

同样先切 npm 镜像，装好 Node.js 22+ 和 FFmpeg，然后打开 Claude Code 或 Codex，发：

```
帮我安装 HyperFrames，然后做一个 60 秒竖屏视频（1080×1920），
内容：介绍《[书名]》的 5 个核心观点，面向抖音发布。
风格：深色背景，每条观点单独一屏，文字逐字入场，结尾引导关注。
加中文配音（用 Edge TTS，声音 zh-CN-XiaoxiaoNeural），加底部字幕。
先运行 npx skills add heygen-com/hyperframes --all 安装工具后开始。
安装依赖请用国内镜像 https://registry.npmmirror.com
```

它会自己安装、写 HTML、用 npx hyperframes render 渲染，给你 MP4。

第一步目标只有一个：**跑通一个 10 秒样片，确认配音和字幕能对上，再谈批量生产。**

第一次从零跑通，现实预期是 1-4 小时。不是「发一句话五分钟出片」——主要时间花在看渲染结果、调整字幕位置、确认配音语速、再渲染。跑顺了之后，出一条视频可能真的只需要 10 分钟。

出来的视频，发布前记得加上「AI 生成」标注，抖音和 B 站现在都有这个要求。
