# Compile 檢查清單

Claude Code 執行 `/compile` 時參照此清單確保步驟完整。

## 每份文件的處理步驟

- [ ] 讀取 `raw/<文件>` 全文
- [ ] 判斷主題 → 對應到哪篇（或哪些篇）`wiki/concepts/` 文章
  - 已有相關文章 → **合併**（補充、不重複）
  - 全新主題 → **新建**（複製 `_template.md`）
- [ ] 寫入/更新概念文章
- [ ] 更新 `wiki/_index.md`（加入條目、更新數量）
- [ ] 更新 `wiki/_summaries.md`（加入摘要區塊）
- [ ] 更新 `wiki/_graph.md`（補充新發現的概念連結）
- [ ] 在原始文件第一行加上 `<!-- processed: YYYY-MM-DD -->`

## 概念文章命名規則

- 使用英文小寫 + 連字號：`transformer-architecture.md`
- 或繁體中文直接命名：`注意力機制.md`
- 避免空格、特殊字元

## 合併原則

- 同一概念的不同來源 → 合併到同一篇文章，在「重要引述」區分來源
- 有衝突的資訊 → 在「詳細說明」中並列，標注各自來源和日期
- 不確定是否同概念 → 建立兩篇，在「相關概念」互相連結

## 索引更新格式

`wiki/_index.md` 文章列表區塊格式：
```markdown
### <主題分類>
- [[concepts/文章名稱|顯示標題]] — 一句話說明 `#標籤`
```
