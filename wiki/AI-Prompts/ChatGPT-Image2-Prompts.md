## #1 日文手寫小字風

**素材**：咖店、食物、空間照
**效果**：照片冒出日文手寫小字，像 IG 限動 / 雜誌 rough memo

```
請觀察照片中的元素，為每一項加上有意義的手寫風註解。

【照片內容】
※ 在這裡填入照片裡的物件（例：冰紅茶、甜甜圈、最可愛的 OO 醬）※

【繪製規則】
・像用白筆畫的細手繪線條
・一筆畫風格 粗略 略帶不均勻感
・沿著物件外緣加上輪廓
・用箭頭或虛線製造視線引導

【文字規則】
・日文手寫字（ひらがな 7 成 + 簡單漢字 3 成）
・短句 像自言自語的留言
・語氣偏「日記、一句話、情緒感」

【註解內容規則】
・飲料 → 味道／溫度／心情（例：すっきり、やさしい甘さ）
・食物 → 口感／好吃程度（例：しっとり、最高）
・空間 → 氛圍（例：落ち着く、いい時間）
・整體 → 一句話總結（例：しあわせすぎる〜）

【裝飾】
・蒸氣、閃亮、愛心、小顏文字 適量加一點
・不要過頭 留白要夠

【成品風格】
・像 IG 限動 / 雜誌的 rough memo 風
・時髦又輕鬆的感覺
```

> 關鍵：「ひらがな 7 成 + 漢字 3 成」比例是日系感核心，預設出來是日文不要改成中文

## #2 個人色彩分析報告

**素材**：人像照
**效果**：方形「個人色彩分析報告」Notion 風 + GOOD vs BAD 對比

```
用我這張人像照做一份方形「個人色彩分析報告」。

【整體風格】
・乾淨極簡的 dashboard UI（Notion 風）
・中文 + 英文混排

【版面內容】
・左側：人物臉部
・色彩季型：春／秋 ／ 夏／冬 + 短關鍵字
・簡單評分：暖色度 warm / 對比度 contrast / 清晰度 clarity
・最佳配色：用色塊圓圈呈現
・GOOD vs BAD 對比：同一張臉 不同顏色配上去看差異
・短日文評語：「これ似合う」「正直微妙」之類

【成品要求】
・視覺優先 極簡 適合分享
```

> 關鍵：「同一張臉不同顏色對比」是爆點；短日文評語比長段落更有日系雜誌感

## #5 3D 動作參考表

**素材**：角色描述文字（不需要照片）
**效果**：4×4 共 16 格灰階 3D 動作參考表（可丟進 Seedance 做跳舞影片）

```
[STYLE] 單色灰階插圖，3D 渲染角色，乾淨的教學參考表，
白色背景，漫畫風格的格子網格布局，技術圖表美學

[LAYOUT] 4x4 網格布局，總共 16 個面板，每個面板由細黑邊框線分隔，
從 1 到 16 編號的儲存格，一致面板大小

[CHARACTER] (角色描述輸入)
例：年輕女性舞者，運動體型，馬尾髮型，
短上衣和寬鬆褲子，運動鞋，所有面板中的相同角色

[PANEL STRUCTURE - per cell]
左上：粗體數字徽章 + 英文標題文字
中心：全身角色姿勢插圖
左下：英文描述文字 (3-4 行)
疊加：指示運動方向的方向箭頭

[ARROWS / MOTION INDICATORS] 彎曲箭頭、直線箭頭、圓形旋轉指示器，
放置在角色周圍以顯示運動流向和方向

[RENDERING STYLE] 高細節 3D 雕塑風格，柔和工作室燈光，細微陰影，
無顏色，灰階陰影，乾淨線條，遊戲概念藝術品質

[NEGATIVE] 無背景場景，無顏色調，無額外角色，無雜亂背景
```

> 關鍵：這張圖是「中介物」，拿到後可丟進 Seedance 2 讓角色照表跳完一支舞；4×4 網格 + 編號是關鍵，別改比例

## #6 日系旅遊雜誌封面

**素材**：旅遊照
**效果**：日系雜誌封面 中英雙語排版 像 anan / Popeye

```
用我上傳的照片製作「高質感旅遊雜誌封面」。

【重要要求】
・保留原照片人物五官與畫面（不可改臉）
・只做「排版設計＋文字＋色調微調」
・整體風格像日系高質感旅遊雜誌（類似 anan / Popeye 風格）
・中英雙語排版

【版面設計】
・大標題：英文雜誌名（例如：TRAVELER / VOYAGE / JOURNAL）
・風格：乾淨、留白、有設計感（每次版型可變化，不要固定）
・配色：依照片調整（海邊＝藍色系 / 城市＝暖色系 / 山景＝自然綠）

【內容設定】
地點：＿＿＿＿（例如：瑞士 / 法國 / 日本）
左上角日期：＿＿年＿＿月（例如：2024 年 9 月）
主標題（中文）：例：瑞士，追尋山與湖的純粹之美
副標（英文）：例：Switzerland, Where Nature Meets the Soul

【雜誌小標】（中英對照增加真實感）
・必訪景點 Must-Visit Destinations
・在地生活 Local Lifestyle
・經典路線 Classic Itineraries
・私房景點 Hidden Gems

【右下角金句】（一句旅行金句，三選一風格）
・勇氣類：勇敢出發，世界會為你讓路
・文青類：走得越遠，越靠近自己
・英文：Travel changes you before you realize it.

【風格要求】
・高級感、乾淨、雜誌排版 不要過度花俏
・字體有層次（標題大、副標小）
・可加入圓形標籤（國家名稱）
```

> 關鍵：「不可改臉」一定要寫；雜誌名用英文比中文有質感；「配色依場景調」AI 才不會出統一色

```
做一張「角色介紹海報」（4:5 直式）

【主題】
2000 年代懷舊感 × 現代創作者風的融合

【主角設定】
年輕創作者（東亞裔 氣質自然沉穩）

海報式構圖（4:5）

【視覺元素】
・底片感質地（膠捲相機般 帶輕微顆粒感）
```

## #8 LOST IN 拼貼海報

```
Create a stylized travel poster/graphic collage for [FRANCE]. The main theme should be a stylish international tourist visiting [FRANCE], clearly presented as a traveler rather than a local. Show a tourist dressed in modern tourist fashion, with details such as a camera, backpack, sunglasses, map or suitcase, exploring the culture and atmosphere of [FRANCE]. The face is 100% identical to the face in the attached image. Place the tourist in a dynamic composition surrounded by iconic architecture, streets, landscapes, landmarks, transportation, food, signage, and cultural elements related to the country. Combine realistic character details with a graphic collage background made of layered paper textures, torn poster edges, sticker elements, grayscale dots, editorial typography, and bold geometric shapes. Use authentic visual motifs [FRANCE], but keep the tourist's look and style fashionable all over the world and clearly alien to the surrounding environment. Add a large, readable headline: "LOST IN FRANCE." A modern, artistic, aesthetic travel poster of premium class, balanced layout, composition worthy of printing. –ar 2:3
```

> 關鍵：「face is 100% identical」必寫；觀光客行頭（相機/背包/地圖）= 跟在地人區隔；將 [FRANCE] 全部換成目標國家

## #9 一週穿搭資訊圖

```
主要部分分為七個平等的垂直欄，代表週一至週日（MON, TUE, WED, THU, FRI, SAT, SUN）。
每一欄都展示了同一位東亞男性的全身穿搭照（與參考圖片中的人物肖像和年齡一致），
他穿著專業/商務服裝，擺出略微不同的姿勢，但都保持專業站姿。

・週四（THU）休閒日：深海軍藍 Polo 衫、卡其色休閒褲、白色運動鞋
・週五（FRI）休閒日：海軍藍扣領襯衫、淺灰色長褲、白色運動鞋
```

## BONUS #11 韓圈迷你分身合成圖

**素材**：人像照（看得到臉，全身或半身都行）
**效果**：你 + 3-7 隻迷你分身在身邊互動 + 短句感性標題 + 手寫塗鴉

### 版本 1（完整版）

```
用這張照片，以照片中的人物為主角，
生成「迷你分身角色們在身邊活著動著的感性合成圖」。

【核心概念】
・「我日常裡的小分身們」
・可愛又調皮 但帶點感性
・IG 感 + 有故事性的圖

1. 人物處理（重要）
・原始人物必須去背使用（臉/姿勢絕對不可改）
・人物放畫面中央或稍微往前
・加自然陰影
・人物外緣加細白邊（貼紙感 不要太粗）

2. 迷你分身角色生成（核心）
・以本人為基礎 生成多個「迷你分身」
・風格：3D 可愛 SD 角色（Roblox / 像素感都可）
・反映本人的臉、髮型、服裝特徵
・尺寸要小（手掌大小感）
・出現多個（3-7 隻）

3. 迷你分身的動作（重要）
每個角色必須在「做動作」 不能靜止：
・跳起來玩  ・揮手  ・模仿本人姿勢
・坐在物件上  ・爬到肩膀／頭上  ・互相對話的感覺
禁止靜止角色

4. 配置
・自然散落在書上 / 包包上 / 肩膀 / 地板 / 手上
・一部分在人前 一部分在人後 → 製造空間感
・加陰影 像真的存在

5. 標題生成（核心功能）
分析圖的氛圍 自動生成短句感性的「中文或是日文標題」
規則：2-5 個字、不要解釋 只傳達「感覺」、自然 感性
範例：今天的瞬間 / 就是好日子 / 小小的一天 / 我的節奏 / 微小的幸福

6. 標題配置
・文字一部分在人後 一部分在人前（立體圖層感）
```
