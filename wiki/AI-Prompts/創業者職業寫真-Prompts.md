# 創業者職業寫真 Prompts

> Startup Founder Portrait — 男女版本
> 適用工具：ChatGPT Image / MJ / DALL·E 3
> 類型：互動模板（需上傳證件照）
> 用途：創業比賽、路演 PPT、團隊頁、公司官網 About、AI 業務場景

---

## #1 女生職業寫真

**風格**：美式 Startup Founder Portrait，科技創業者氣質
**比例**：4:5 豎版
**需要的素材**：原始證件照
**標籤**：#人像 #職業寫真 #創業者 #女性 #科技

### Prompt

```
女生職業寫真提示詞：

請基於我上傳的原始證件照，生成一張真實拍攝感的職業寫真照，適用於創業比賽、路演PPT、團隊介紹頁、公司官網 About 頁面、AI業務場景展示。

請嚴格保留原始證件照中的真實面部特徵，包括臉型、五官比例、眉眼特徵、鼻子和嘴巴的真實結構、年齡感和整體氣質。不要大幅改變長相，不要過度美顏，不要把人物生成成"AI假臉"或網紅寫真臉。最終效果要像真實攝影師拍攝的高質量職業寫真，而不是AI合成圖。

整體風格請做成：

美式職業寫真、startup founder portrait、AI/互聯網/科技創業者氣質。人物要顯得年輕、自然、可信，專業但不刻板，輕松但不隨意，有產品人、創業者、互聯網從業者的氣質。

【構圖】
4:5豎版
半身到上半身構圖
人物看向鏡頭
姿態自然放鬆
可以輕微側身坐姿，臉轉向鏡頭
一隻手自然搭在椅子、腿上或身體一側
不要雙手插胸
不要僵硬站姿
不要刻意擺拍感
【表情】
平靜、自信、自然
微微友好，但不要誇張笑容
看起來聰明、可靠、有親和力
像真實AI創業者、產品經理或互聯網從業者
【光線與背景】
像真實棚拍職業照
光線柔和、均勻、清晰
面部自然立體
保留真實膚質，不要過度磨皮
可以保留輕微自然細節，例如真實頸紋、輕微膚質紋理、細小瑕疵
背景為簡潔的淺灰色、米灰色、淺暖灰色或淺中性色純背景
不要複雜辦公室布景
整體乾淨、現代、克制
【穿搭】

請採用極簡、年輕化、互聯網從業者 / 創業者風格，參考優衣庫風格 + 喬布斯式極簡感 + clean tech founder aesthetic。

推薦穿搭方向：
外層：藏青色 / 深牛仔藍 / 深灰藍襯衫或輕薄外套
內搭：深棕色 / 深灰色 / 黑色 / 炭灰色純色T恤或針織上衣
服裝允許有自然真實的褶皺
不穿正式西裝
不打領帶
不要傳統商務白襯衫套裝
不要誇張首飾
不要明顯網紅風或甜美風
【真實感要求】
髮絲真實自然，有層次感，不要頭髮像塑料
髮色自然，可略帶棕色、悶青感或自然綜合色調，不要死黑色塊
膚色自然，不要過白
允許保留輕微真實瑕疵
不要廉價影樓風
不要網紅精修感
不要明顯AI生成痕跡
請確保最終成片看起來像：

"真實攝影師拍攝的、適合創業比賽與路演材料使用的年輕女性科技創業者職業寫真"。

關鍵詞：

realistic, photorealistic, startup founder portrait, clean professional portrait, young tech entrepreneur, natural, minimal, relaxed professional, premium but understated, not overly formal, not overly retouched, not obviously AI-generated.
```

## 男女版差異對照

| 要素 | 女生版 | 男士版 |
|------|--------|--------|
| 穿搭外層 | 襯衫或輕薄外套 | 襯衫、輕薄夾克或極簡外套 |
| 禁忌穿搭 | 傳統套裝、誇張首飾、網紅/甜美風 | 傳統西裝襯衫、誇張配飾 |
| 髮型要求 | 自然層次，不要死黑色塊 | 自然蓬鬆、兩鬢俐落，不要劉海過整齊 |
| 髮色 | 可帶棕色/悶青/綜合色調 | 自然黑或略帶棕調 |
| 膚色 | 不要過白 | 不要過白，可偏暖或略深 |

### 共同核心準則

- 嚴格保留真實面部特徵
- 不過度美顏 / 不做 AI 假臉
- 極簡創業者風格（優衣庫 + 喬布斯式）
- 淺中性色純背景
- 4:5 豎版，半身構圖
- 關鍵詞：realistic, photorealistic, startup founder portrait
