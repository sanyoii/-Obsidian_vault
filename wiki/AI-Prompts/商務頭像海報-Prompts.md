## #1 正式商務檔案頭像海報

**風格**：證件照級商務頭像 + 底部資訊欄
**比例**：1:1 方形
**需要的素材**：人像照片
**標籤**：#人像 #商務 #頭像 #海報 #職業

### Prompt

```
請基於我上傳的人像照片生成一張正式商務檔案頭像海報。保留人物真實身份特徵、五官比例、臉型基礎和整體氣質，不要改變人物身份。

可以適度優化面部輪廓，使臉部線條更清晰、自然、上鏡；平滑皮膚質感，減少瑕疵、暗沉和膚色不均，但不要過度磨皮，保留真實皮膚細節和自然光影。

請根據人物臉型設計一款匹配的商務髮型。髮型應乾淨利落、成熟專業、適合正式場合，髮絲自然、有層次，不誇張。請為人物搭配正式商務穿搭，例如深色西裝外套、白色或淺色襯衫，可搭配領帶。整體造型應高級、簡潔、專業、可信賴。

畫面為正面半身肖像，人物居中，直視鏡頭，表情自然自信。背景為純白色素色背景，光線柔和均勻，類似專業證件照、企業頭像攝影或大學官網個人檔案照。整體風格乾淨、正式、商務、高清寫實攝影質感，方形比例 1:1。

畫面下方預留簡潔資訊欄，並添加現代簡潔排版文字：
請提示使用者輸入所需要的資訊, 例如:
 (可把以下當作例子提示給使用者看)
姓名：[請使用者輸入]
身份/職位：[請使用者輸入]
專業/部門/機構：[請使用者輸入]
Email: [請使用者輸入]
電話: [請使用者輸入]
＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝
若使用者無輸入任何資訊, 則略過這部分

重要文字規則：

如果用戶輸入的姓名、身份、職位、專業、部門、機構或其他需要顯示在圖片上的文字是中文或其他語言，請先將這些內容翻譯成自然、準確、正式的英文，再放入圖片中。除非用戶明確要求保留中文，否則圖片中不要顯示中文文字。

排版要求：

第一行姓名使用深藍色粗體大字號英文文字；第二行和第三行使用黑色常規字號英文文字。整體排版參考大學官網個人檔案、學術會議人物介紹卡片或專業商務頭像海報風格。
```

### 設計要素拆解

| 要素 | 說明 |
|------|------|
| 構圖 | 正面半身居中，直視鏡頭 |
| 背景 | 純白素色，柔和均勻光線 |
| 穿搭 | 深色西裝 + 白/淺色襯衫，可搭領帶 |
| 髮型 | 依臉型設計，乾淨利落專業 |
| 美化程度 | 適度優化，不過度磨皮 |
| 資訊欄 | 底部：姓名（深藍粗體）+ 職位 + 機構 |
| 文字語言 | 預設翻譯成英文，除非要求保留中文 |
| 比例 | 1:1 方形 |
| 參考風格 | 大學官網個人檔案 / 學術會議人物卡 |
