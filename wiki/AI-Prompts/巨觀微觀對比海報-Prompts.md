# 巨觀微觀對比海報 Prompts

> 「放大數千倍的織物 × 微小人影 × 鏡面反射」三層結構視覺框架
> 適用工具：ChatGPT Image / MJ / DALL·E 3
> 比例：16:9 橫屏
> 類型：系列模板（共用五層結構，替換主題即可）

---

## 共用結構框架

所有 Prompt 均遵循相同的五層視覺結構：

| 層次 | 佔比 | 作用 |
|------|------|------|
| 1. 頂部高壓形態 | ~60% | 放大數千倍的織物/服飾面料，如巨大山脈般壓頂 |
| 2. 中央呼吸帶 | ~10% | 極窄極亮的橫向光帶，微小人影踏光而行 |
| 3. 底部反射介質 | ~30% | 鏡面靜水，倒映上方織物與光帶，水汽繚繞 |
| 4. 色彩與氛圍 | — | 乾淨、現代、簡約，摒棄雜亂與復古 |
| 5. 文字層 | — | 極細現代字體，半透明懸浮，座標/詩號 |

核心手法：**尺度極端反差**——頭頂是遮天蔽日的巨大織物，腳下是無垠虛空，將人物「氣場」具象化為扭曲空間的物理存在。

## #1 《青龍之息》— 關羽

**主題**：關羽 · 忠義 · 三國
**織物**：深綠色龍紋戰袍（金色鱗片刺繡）
**標籤**：#三國 #關羽 #巨觀微觀 #海報 #16:9

### Prompt

```
視覺圖像構思：其名為《青龍之息》 1. 頂部的高壓形態（巨集觀視角）： 畫面頂部並非天空，而是被放大了數千倍的關羽綠色龍紋戰袍的邊緣。深綠色的絲綢如同沉重的雲層或柔韌的帷幕，從上方垂落，佔據了畫面 60% 的空間。你可以清晰地看到布料上金色的鱗片刺繡，每一片鱗片都閃爍著冷峻的金屬光澤，如同巨龍壓頂。戰袍形成的巨大弧形邊緣遮擋住大部分光源，只在縫隙中漏出幾縷如利劍般的金色銳光。 2. 中央的呼吸帶（微觀對比）： 在畫面正中央的一道橫向極亮區域，形成了一個狹窄但極其純淨的「呼吸空間」。在這道光芒中，一個極小的關羽剪影（或是一匹只有指甲蓋大小的赤兔馬與長髯身影）正靜靜地踏光而行。這種尺度上的極端反差——頭頂是足以遮天的袍服，腳下是無垠的虛空——瞬間將關羽的「氣場」具象化為一種足以扭曲空間的物理存在。 3. 底部的反射介質（深邃層次）： 畫面底部是一層如同鏡面的深色靜水。它完美地倒映著上方沉重的綠色戰袍與中央的亮點。水面上飄浮著淡淡的、透明的白色水汽（霧靄），弱化了邊界感。反射的光線被拉伸成一條條垂直的亮線，前景處的色彩逐漸過渡到深邃的墨綠與玄黑，營造出一種「大音希聲」的寂靜感。 4. 色彩與氛圍： 主色調： 乾淨的「青龍綠」（Forest Green）與「冷冽金」（Metallic Gold）。 高調區域： 背景採用半透明的乳白色，像是在極遠處燃燒的純淨聖光。 輔助色： 低飽和度的灰紫色與冷青色，用於陰影細節。 氛圍： 摒棄掉傳統戰場的混亂，轉而追求一種現代、簡約、潔淨的視覺力量。 5. 文字層（現代信息感）： 在畫面的一側，漂浮著極細、寬間距的現代字體： 主標題： 「忠義」 (LOYALTY) —— 巨大但極淺，半透明。 副標題： 座標、歷史紀年或簡短的詩號 —— 「單騎千里，萬夫莫敵」，以極小的字號、稀疏地排列在反光帶邊緣。 將長寬比設為 16:9
```

| 輔助 | 低飽和灰紫 + 冷青 |

## #2 《琉璃春水 · 喬》— 大喬

**主題**：大喬 · 柔美 · 三國
**織物**：淡紫色與藕粉色絲綢織錦（花卉刺繡）
**標籤**：#三國 #大喬 #巨觀微觀 #海報 #16:9

### Prompt

```
視覺圖像構思：其名為《琉璃春水 · 喬》 1. 頂部的高壓形態（極致柔美的視覺重壓）： 畫面頂部被放大了數千倍的淡紫色與藕粉色交織的絲綢織錦所佔據。這並非普通的布料，而是取自大喬服飾上的那種精緻花卉刺繡（如你提供圖片中的繁複紋樣）。綢緞如同溫柔的粉色雲層或垂幔，從頂部向中心壓迫。邊緣呈現出連綿的弧線，如同花瓣的邊緣，在重疊處漏出如晨曦般的半透明、狹窄的淡金色光隙。 2. 中央的呼吸帶（微小而堅韌的生命力）： 在畫面中心那條橫向的、極度明亮的「呼吸帶」中，一個極其微小的大喬剪影靜靜矗立或漫步。她保留著圖片中那樣端莊的姿態，雙手交疊，長髮如絲。在巨大的、如山脈般的綢緞垂幔對比下，這個微小的人影顯得無比精緻，彷彿歷史長河中一朵靜謐綻放的靈魂，展現出「以柔克剛」的霸氣。 3. 底部的反射介質（煙雨江南的透明感）： 地面是一層極薄的、如琉璃般的淺水。水面微動，捕捉並拉伸了上方紫色垂幔的倒映。水汽與薄霧（Mist）在前景繚繞，將色彩漫射成柔焦的質感。這裡的色彩從底部的深紫灰逐漸過渡到中央的純淨亮白，營造出一種「春水如鏡」的通透感。 4. 色彩與氛圍： 主色區域： 乾淨的「藕粉色」與「丁香紫」（取自圖片中大喬的外袍）。 背景與光影： 高調的「乳白色」半透明區域，象徵江南煙雨後的晴空。 輔助與情感色： 「低飽和的青灰色」與「點睛的點金」（模擬髮飾的光澤）。 氣息： 清晰、寧靜、明亮，完全避開渾濁，呈現出一種現代時尚大片與東方古韻結合的高級感。 5. 文字層（現代信息層）： 懸浮於水面反射層之上，使用極細的現代排版： 主標題： 「QIAO」 —— 字體極大且透明度極高（約 10%-15%），橫跨畫面。 子信息： 在右下角或左側，以稀疏的字距寫著：「江東有佳人，絕世而獨立」。字體輕盈，像浮在空氣中的微塵。 將長寬比設為 16:9
```

## #3 《未知的未來》— 學生

**主題**：學生 · 成長 · 秩序與自由
**織物**：深綠色百褶裙 + 深藍色校服面料
**標籤**：#學生 #校園 #巨觀微觀 #海報 #16:9

### Prompt

```
1. 頂部的高壓形態（規訓與秩序的褶皺）： 畫面頂部被放大了數千倍的深綠色百褶裙褶皺與深藍色校服面料所佔據。這些褶皺如同巨大的建築結構或柔軟的垂幔，從上方重重壓下。每一道褶皺都像是一座山巒，邊緣鋒利而整齊，象徵著學校規律的秩序。在百褶裙的縫隙間，漏出幾縷極其明亮的、如同下課鈴聲般清澈的白色光線，形成狹窄而神聖的透光帶。 2. 中央的呼吸帶（渺小個體的成長空間）： 在畫面中心最明亮、最純淨的橫向亮帶中，一個極其微小的學生剪影（穿著與原圖相同的制服、戴著黑框眼鏡）靜靜地漫步。在這道代表「未來」與「自由」的呼吸帶中，微小的人影與上方巨大的校服紋理形成鮮明對比——這種尺度感傳達出一種「在龐大的體制與期待下，依然擁有一片清澈心靈空間」的霸氣與韌性。 3. 底部的反射介質（雨後的操場或晨間的長廊）： 地面是一層透明且帶有微波的反射介質，像是雨後初晴的操場積水，或是擦拭得極其光亮的教學樓長廊。它捕捉了上方深藍色與深綠色的主調，反射光線被垂直拉伸，閃爍著冷調的微光。前景處籠罩著半透明的、淡淡的水汽，隨著視線移近，顏色逐漸加深為深沉的墨藍色，保持著柔焦的層次感。 4. 色彩與氛圍： 主色調： 乾淨的「學院藍」 (Navy Blue) 與 「墨綠色」 (Forest Green)，取自原圖的西裝與裙子。 輔助色： 低飽和度的「純白」（襯衫）與「淡天藍」（領結色彩的映射）。 強調色： 微弱但清晰的「銅金色」（取自校徽或鈕扣的光澤），點亮沉悶的空間。 氣息： 清晰寧靜，像早晨六點的校園，空氣中帶著一點微涼與透明感，完全摒棄雜亂，呈現出一種高端、現代的視覺層次。 5. 文字層（現代信息層）： 以稀疏、輕盈的排版懸浮於空間中： 主標題： 「STUDENT / 01」 —— 字體大而淺，半透明，像是在玻璃屏上的投影。 子信息： 以極小字號寫著：「CHAPTER: THE UNKNOWN FUTURE」 與一些如坐標般的數值，懸浮在反光區域上方，增加未來感。 將長寬比設為 16:9
```
