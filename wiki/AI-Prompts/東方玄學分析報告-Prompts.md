# 東方玄學分析報告 Prompts

> 手相 / 面相 / 手臉組合的視覺化玄學分析報告圖
> 適用工具：ChatGPT Image（需上傳手部或面部照片）
> 類型：互動模板（上傳照片即可）

## #1 東方玄學分析報告圖

**風格**：命理報告 + 古籍玄學註解 + 高級視覺海報
**比例**：3:4
**需要的素材**：手部照片 / 面部照片 / 手臉組合照片
**標籤**：#命理 #手相 #面相 #分析報告 #東方玄學 #海報

### Prompt

```
請根據我上傳的【手部照片 / 面部照片 / 手臉組合照片】，創作一張高完成度、有設計感、適合分享的「東方玄學分析報告圖」。
這不是普通的照片說明，也不是簡單的娛樂占卜，而是一張結合【中國傳統手相、面相、易經五行、中醫望診氣色理論】的視覺化分析圖。整體應呈現出"命理師分析報告 + 古籍玄學註解 + 高級視覺海報"的感覺，讓用戶能直觀看到關鍵特徵、對應解釋和趨勢預警。
【識別與分析要求】
請先判斷圖片中包含的是：
1. 手部：重點分析掌紋、掌丘、手型、指形、指節、指紋走勢、生命線、智慧線、感情線、事業線、財運線等可見特徵。
2. 面部：重點分析額頭、眉眼、鼻梁、顴骨、法令、嘴型、下巴、面部輪廓、氣色、五官比例與整體神態。
3. 如果同時包含手和臉，請綜合分析，不要重復堆砌，要形成統一判斷。
請至少提煉【10個關鍵分析點】，每個分析點都要包括：
- 可見特徵：指出照片中能看到的具體位置或形態。
- 玄學解釋：結合手相、面相、易經五行或傳統命理語言進行分析。
- 趨勢提示：用"傾向於、容易、需要注意、適合、未來一段時間可能"等方式表達。
- 行動建議：給出一句現實可執行的提醒，例如情緒管理、作息、事業節奏、人際關係、財務規劃等。
【標注要求】
請在圖片中使用清晰的線條、箭頭、圓圈或編號標籤，標明每個關鍵位置：
- 手相圖可標注：生命線、智慧線、感情線、事業線、掌丘、指節、拇指根部、食指長度、無名指比例、掌心紋路交匯點等。
- 面相圖可標注：額頭、眉眼、鼻梁、顴骨、法令紋、嘴角、下巴、耳形、面部中庭、氣色區域等。
- 每個標注點用 01、02、03……編號，對應右側或下方的分析說明。
- 線條要細緻、優雅，不要雜亂，不要遮擋主體。
【視覺風格】
整體風格要符合東方玄學、命理、手相、面相的調性：
- 主色調：米白、宣紙色，點綴：深墨黑、玄青、古銅金、暗紅
- 風格氣質：神秘、克制、高級、古籍感、命理報告感。
- 可加入輕微元素：八卦紋、羅盤刻度、五行符號、古籍邊框、星盤細線、朱砂印章、宣紙紋理。
- 不要做成恐怖風、低俗算命攤風，也不要過度賽博朋克。
- 排版要像高級雜誌信息圖，而不是雜亂截圖。
【版式設計】
Make the aspect ratio 3:4
版面結構建議：
1. 頂部：標題區 
  標題可為「手相面相玄學分析報告」「東方命理特徵解讀」「掌紋與面相趨勢觀察」等，要符合用戶上傳的圖片內容。
2. 中間：主體照片分析區 
  保留手部或臉部主體，加入編號、箭頭和關鍵線條標注。
3. 側邊或下方：十點分析區 
  每一點用簡短標題 + 2-3行說明，不要文字太小。
4. 底部：綜合結論區 
  總結此人的性格傾向、事業財運、人際情感、健康作息和近期提醒。
【內容語氣】
分析語言要有傳統玄學味道，但不要絕對化，不要說"必定""一定會發財""一定有災"。 
可以使用：
- "此紋路顯示其人多半……"
- "從五行氣象看，偏向……"
- "此處若紋路明顯，通常代表……"
- "近期需要留意……"
- "適合走……方向"
- "建議在……方面做調整"
【輸出目標】
請最終生成一張完整的視覺分析圖，至少包含10個編號分析點。 
整體要讓人一眼看出"哪裡被分析了、對應什麼含義、有什麼提醒"，既有玄學氛圍，又有專業排版和高級設計感。
注意：
- 只基於圖片中可見特徵分析，不要編造看不見的信息。
- 不做醫學診斷，不給出疾病結論；中醫氣色內容只作為傳統文化角度的生活提醒。
- 不要出現過多小字，確保手機上也能清楚閱讀。
```
