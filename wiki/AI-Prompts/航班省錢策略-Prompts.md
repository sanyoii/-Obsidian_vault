# 航班省錢策略 Prompts

> 三種版本：完整分析 / 快速查詢 / 突發優惠
> 適用工具：ChatGPT / Claude / 任何長對話 AI
> 類型：互動模板（填入出發地、目的地、日期）

---

## #1 完整版 — 全面分析（7 大策略）

**用途**：完整規劃，涵蓋所有省錢面向
**標籤**：#旅遊 #航班 #省錢 #完整分析

```
我想從[出發城市/機場]飛往[目的地]，時間在[日期範圍或月份]。

請你同時扮演航班定價分析師、旅行黑客、預算旅行專家、隱蔽城市訂票專家、行程優化師、航班交易獵手，以及高級航班黑客，綜合分析以下面向：

1. 找出基於航空公司定價模式與歷史趨勢的最便宜預訂時間窗口（具體日期與時間）。

2. 比較該日期範圍或月份內所有可能的出發/返回日期，指出最便宜組合並解釋原因。

3. 建議出發地與目的地 100 公里內可能更便宜的替代機場，並估算可節省的費用。

4. 提出目的地作為中轉站的隱蔽城市訂票策略，並提醒相關風險（如行李托運）。

5. 建議可能比直達往返更便宜的多城市或開口行程，並解釋如何預訂。

6. 提供我應該監控的網站、論壇與提醒服務，以捕捉超低價或錯誤票價。

7. 分析是否透過不同貨幣或航空公司其他國家網站購票能更便宜，並說明安全操作方式。

最後，請整合以上分析，給我一份最具成本效益且可行的航班建議。
```

### 7 大策略速覽

| # | 策略 | 說明 |
|---|------|------|
| 1 | 最佳訂票時間 | 定價模式 + 歷史趨勢 |
| 2 | 靈活日期 | 比較所有出發/返回組合 |
| 3 | 替代機場 | 100km 內更便宜機場 |
| 4 | 隱蔽城市 | 目的地作中轉站（附風險提醒） |
| 5 | 多城市行程 | 開口行程可能更便宜 |
| 6 | 錯誤票價 | 監控網站/論壇/提醒服務 |
| 7 | 貨幣差異 | 不同國家網站/貨幣購票 |

## #2 簡化版 — 快速查詢

**用途**：日常快速查詢最低票價
**標籤**：#旅遊 #航班 #省錢 #快速查詢

```
我想從[出發城市]飛往[目的地]，時間在[日期範圍]。

請幫我找出最便宜的出發/返回日期，並建議是否有替代機場或多城市行程能更省錢。
```

---

## #3 進階版 — 突發優惠

**用途**：捕捉錯誤票價、限時促銷
**標籤**：#旅遊 #航班 #省錢 #錯誤票價 #進階

```
我想從[出發城市/機場]飛往[目的地]，時間在[日期範圍或月份]。

請你扮演航班交易獵手與高級航班黑客，幫我專注在以下面向：

1. 找出近期可能出現的錯誤票價或超低價票，並提供我應該監控的網站、論壇與提醒服務。

2. 分析航空公司或 OTA（線上旅行社）在不同貨幣、不同地區網站的定價差異，指出是否有購票漏洞。

3. 提醒我這些策略的風險（例如退票限制、行李政策、付款安全性），並提供安全操作建議。

4. 最後，給我一份「立即可行」的行動清單，讓我能快速追蹤或下手。
```

## 版本選用指南

| 情境 | 推薦版本 |
|------|---------|

| 看到促銷消息或想撿錯誤票價 | #3 進階版 |
