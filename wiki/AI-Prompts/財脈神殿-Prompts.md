# 財脈神殿 Prompts

> 結合命理分析 + AI 圖像生成的「財脈神殿」互動式 Prompt
> 適用工具：ChatGPT Image / Claude / 任何支援長對話的 AI
> 類型：互動模板（需填入個人資料）

---

## #1 財脈神殿 — 命理能量場景 + 運勢分析報告

**風格**：電影級場景設計、象徵性建築、能量分析報告
**輸出**：圖像 + 分析報告
**標籤**：#命理 #能量 #場景 #分析報告 #互動模板

### Prompt

```
請根據我的資料， 設計並生成我的專屬「財脈神殿」。
以靈魂能量、潛意識、人生藍圖與未來發展為核心。
請先感應我的整體能量狀態，再設計完整宮殿。
我希望宮殿呈現電影級場景設計，細節豐富且具有象徵意義。
除了生成「財脈神殿」圖片之外，
請詳細分析我的財運、貴人運、健康、感情與整體能量狀態及運勢。
並告訴我：
我目前最大的優勢
我最需要補強的地方
未來最值得發展的方向
三個可以在現實生活中執行的建議
最後請 以財脈神殿分析報告的形式呈現。
以下是我的資料：
出生年月日：
出生時間（填時辰即可）：
個性特質：
興趣愛好：
人生最有成就感的一件事？
人生最大的低潮或挫折？
你從那段經歷學到什麼？
目前職業：
目前收入來源有哪些？
目前最想改善的事情：
目前最想達成的目標：
你認為最大的金錢障礙是什麼？
最喜歡的建築風格：
最喜歡的顏色或能量色？
是否有養寵物：
```

### 使用方式

1. 複製上方 Prompt
2. 將「以下是我的資料」後的欄位逐一填入
3. 貼到 ChatGPT（需有圖像生成功能）或其他 AI
4. AI 會先生成財脈神殿圖像，再輸出完整分析報告

### 報告產出結構

| 區塊 | 內容 |
|------|------|
| 財脈神殿圖像 | 電影級場景，反映個人能量與建築偏好 |
| 財運分析 | 財運、貴人運、健康、感情、整體能量 |
| 優勢 | 目前最大的優勢 |
| 待補強 | 最需要加強的面向 |
| 發展方向 | 未來最值得發展的方向 |
| 行動建議 | 三個可執行的現實建議 |

### 填寫欄位說明

| 欄位 | 用途 |
|------|------|
| 出生年月日 / 時辰 | 命理計算基礎 |
| 個性特質 / 興趣 | 能量特徵與宮殿風格依據 |
| 成就 / 低潮 / 學到什麼 | 靈魂藍圖與成長軌跡 |
| 職業 / 收入 | 財運分析依據 |
| 想改善 / 目標 | 運勢建議方向 |
| 金錢障礙 | 財脈阻塞分析 |
| 建築風格 / 顏色 | 宮殿視覺設計參考 |
| 寵物 | 能量場輔助元素 |
