## #1 鏤空字體景觀 Meta 模板

**風格**：文字即結構骨架，場景從文字內部浮現，人物穿越文字層
**比例**：依需求自訂（範例為 16:9 橫屏）
**標籤**：#鏤空字體 #海報 #文字景觀 #通用模板 #人像

### Meta Prompt（通用框架）

```
創作一幅視覺衝擊力極強的圖像，將文字與圖像圍繞任何主題融合：第一眼，觀者的目光便會被佔據畫面中心區域的超大號、醒目的主題文字或符號所吸引——它並非簡單的標題，而是圖像的結構骨架，透過大面積的留白、鏤空的窗口和斷續的筆畫來承載主題場景，文字內部則展現出與主題相關的真實環境、材質紋理或敘事片段；核心主題對象位於視覺中心，並延伸至文字層之外，部分遮蔽了巨大的文字，從而形成清晰的層次結構："背景被文字剖開，主題從文字中浮現"。圖像頂部保留了簡潔、克制、間距較大的小型資訊文字，而底部則以更醒目的主標題和極簡的輔助訊息為特色，其清晰的排版節奏更像是精心設計的宣傳圖，而非普通的插圖。色彩的運用源自於主題本身的材質、環境和氛圍：大面積高亮度、乾淨的背景提供了呼吸空間和結構性的留白；主題環境色作為中等大小的鮮豔輔助色；主體顏色清晰易辨；極少的高飽和度強調色僅用於情感焦點和信息節點；深色調主要用於增強文字的可讀性和視覺分量；整體效果保持了亮度、清晰度和乾淨度，並具有清晰的色調範圍，允許呈現微妙的紙張紋理或輕微的印刷顆粒，但不會令圖像顯得髒污、灰暗、復古或模糊。邊緣應清晰銳利，大字部分應有強勁有力的切割線；內部圖像和外部留白營造出清晰的視覺張力；主體部分採用自然光和微妙的前景壓縮，最終呈現出高端宣傳主視覺效果，將主題人物、物體或概念轉化為一幅巨大的文字景觀。
```

### 使用方式

在 Meta Prompt 後面加上「適用對象」段落，替換為你的具體主題：

```
—————— 適用對象：[你的主題描述]
- 比例：[16:9 / 3:4 / 1:1 等]
- 大字：[要鏤空的文字]
- 內景：[文字內部要展現的場景]
- 主圖：[穿越文字層的主體人物/物體]
- 文案：[頂部/底部的排版文字]
```

## 範例：攝影工作室「九份」封面

```
—————— 適用對象：攝影工作室 Pound 的封面，16:9 橫屏，大字"九份"，內景展現蜿蜒的豎崎路石階、高掛的紅燈籠、古色古香的茶樓建築，以及遠處迷濛的山海景致與遊客的剪影。

主圖：一位手持復古相機（或撐著透明雨傘）的年輕旅人從「九」字的筆畫開頭走出，身著乾淨明亮的文藝風格服裝，呈現出自然、鬆弛的街頭漫步鏡頭感。

文案："別讓山城的浪漫困在手機裡"，角落補充說明："街巷寫真/旅拍肖像/週末檔期現已開放預訂"。
```

## 設計原理拆解

| 層次 | 作用 | 說明 |
|------|------|------|
| 文字層 | 結構骨架 | 超大鏤空字佔據畫面中心，筆畫即窗口 |
| 場景層 | 內容填充 | 文字內部展現主題環境、材質、敘事 |
| 主體層 | 立體穿插 | 人物/物體從文字中走出，部分遮蔽文字 |
| 資訊層 | 排版節奏 | 頂部小字克制、底部主標題醒目 |

### 色彩系統

| 色彩角色 | 用途 |
|---------|------|
| 高亮度乾淨背景 | 呼吸空間、結構性留白 |
| 主題環境色 | 中等面積鮮豔輔助色 |
| 主體色 | 清晰易辨的核心色 |
| 高飽和強調色 | 極少量，用於焦點/節點 |
| 深色調 | 增強文字可讀性與視覺分量 |

### 質感要求

- 允許微妙紙張紋理 / 輕微印刷顆粒
- 不可髒污、灰暗、復古、模糊
- 邊緣清晰銳利
- 大字切割線強勁有力
