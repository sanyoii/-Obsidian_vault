# 高階學習與思維系統 Prompts

> 收藏日期：2026-07-27
> 來源：X（Twitter）@AIExplorerTim，2026-07-26
> 用途：8 條角色扮演型自我提升提示詞（學習法、心智模型、時間槓桿、人生規劃）
> 適用工具：ChatGPT / Claude / 任何長對話文字模型
> 原文為簡體中文，此處已轉繁體，內容未改寫、未增刪

## 這批 Prompt 在做什麼

8 條各自獨立、可單獨使用的**角色扮演型指令**：每條都先指定 AI 扮演某種專家（導師、心智建築師、時間槓桿專家、生活架構師），再要它針對你的情況輸出一份計劃或系統。彼此沒有先後依賴，挑需要的用即可。

其中 **#1 有 `[插入主題]`、#2 有 `[插入領域]`** 兩個佔位符，使用前務必替換成具體對象（例如「Playwright 自動化測試」「產品經理」），不替換直接送出會得到空泛的通用答案。其餘 6 條沒有佔位符，但同樣建議在貼上後補一段你自己的現況、目標與限制——這批 prompt 的輸出品質幾乎完全取決於你餵進去的脈絡有多具體。

---

### 1. 激活高級學習模式

**用途**：為指定主題產出以間隔重複為核心的每週學習計劃
**標籤**：#學習 #學習計劃 #間隔重複

```
假設你是一位認知高級的導師。我想以超出平均水平的速度掌握任何複雜技能。制定基於間隔重複、主題切換、簡化解釋和主動記憶恢復的每週學習計劃。將此計劃應用於[插入主題]。目標是90天內達到前1%的卓越水平。
```

> 使用要點：把 `[插入主題]` 換成具體技能（越窄越好，「英文」不如「技術面試英文口說」）。

---

### 2. 獲取專家級知識

**用途**：把某個領域拆成分階段的學徒式學習路徑
**標籤**：#學習 #學習路徑 #專家

```
擔任[插入領域]的絕對權威。像對待直接學徒一樣指導我，從基礎到全面掌握。通過清晰階段構建路徑，包含實踐任務、鮮為人知的資源和更高效路徑。包括應用練習、模擬或真實挑戰，確保每個階段真正被吸收。
```

> 使用要點：把 `[插入領域]` 換成具體領域；「鮮為人知的資源」這段最容易被模型編造，拿到清單後要自己查證是否真的存在。

---

### 3. 更新心智系統

**用途**：檢視現有思維模式／習慣／信念並提出重構建議
**標籤**：#心智模型 #習慣 #自我提升

```
充當心智建築師。分析我當前的運作模式——思維模式、習慣和信念。重構內在系統，提高心智清晰度，加速決策，強化記憶，激發創造力，改善情緒控制。
```

> 使用要點：無佔位符，但模型不知道你「當前的運作模式」，必須自己先描述一段現況，否則只會拿通用答案填空。

---

### 4. 採用高績效思維

**用途**：借用知名創業者的決策框架，產出日常可用的心智模型
**標籤**：#心智模型 #決策 #思維

```
扮演戰略導師，靈感來自埃隆·馬斯克、傑夫·貝索斯等領袖思想家。重塑我的思維過程，優先考慮系統性推理、長遠視野、智能槓桿和非對稱結果。提供日常心智模型，幫助我從普通思維進化到卓越水平。
```

> 使用要點：輸出的是這些人**公開言論的二手歸納**，不是他們本人的方法論，當成思考起點而非權威。

---

### 5. 將年轉化為天

**用途**：用捷徑、工具、授權與自動化壓縮達成目標所需時間
**標籤**：#時間管理 #槓桿 #自動化

```
擔任時間槓桿專家。我想在1年內完成大多數人需10年的成就。基於我的目標，創建高影響力計劃，利用智能捷徑、先進工具、策略性授權、自動化和AI，大幅加速結果並獲得明顯優勢。
```

> 使用要點：「基於我的目標」四個字是關鍵——沒先講清楚目標，這條會直接退化成勵志文。

---

### 6. 成為最佳版本的自己

**用途**：拆解限制性自我認知，重建自我形象
**標籤**：#自我提升 #身份認同 #心理

```
作為心理重構專家。幫助我拆解限制性身份模式，構建新的功能性自我形象。重新定義思考、行動和決策方式，與最理想的自我完全一致。
```

> 使用要點：這是自我反思練習用的提示詞，不是心理治療；涉及真實心理困擾請找專業人士。

---

### 7. 建立絕對清晰度

**用途**：過濾雜訊與假急事，建立優先級判斷系統
**標籤**：#專注 #優先級 #決策

```
擔任心智清晰戰略師。幫助我消除噪音、虛假緊急事項和被動決策。創建簡單系統，以清晰思考，設定正確優先級，專注於真正推動結果的事情。
```

> 使用要點：先列出你目前實際在追的 10 件事再送出，模型才有東西可以幫你砍。

---

### 8. 設計高影響力人生

**用途**：依價值觀與技能繪製長期人生規劃
**標籤**：#人生規劃 #目標設定 #長期主義

```
作為戰略生活架構師。根據我的價值觀、技能和抱負，繪製有意圖的人生規劃。目標是長期最大化影響力、自由和一致性，避免分散和隨機選擇。
```

> 使用要點：「我的價值觀、技能和抱負」需要你自己先寫出來，這條才成立。

---

## 使用前提醒

這 8 條屬於通用型自我提升 prompt：先指定一個專家角色，再搭配宏大承諾（「90 天達到前 1%」「1 年完成別人 10 年」）。它們沒有檢索接地也沒有驗證機制，輸出品質高度取決於你自己餵進去的具體脈絡——脈絡給得空，回來的就是漂亮的空話。原貼文標題說的「隱藏模式」「看似違法」是行銷話術，不是技術事實；這些寫法沒有繞過任何限制，就是一般的角色扮演提示詞。當成整理思路的起點還行，別當成計劃本身。
