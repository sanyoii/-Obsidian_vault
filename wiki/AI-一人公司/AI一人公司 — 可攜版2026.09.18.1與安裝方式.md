## 安裝順序

1. 下載 ZIP 並完整解壓。
2. 在桌面 App 選取內層 `AI-一人公司` 資料夾；這一層應看得到 `AGENTS.md`、`SETUP.md` 與 `offline/`。
3. Claude Code 使用 Local；Cowork 選取並授權資料夾。ChatGPT Codex 使用本機 Local；Work 使用 Work locally。
4. 第一次貼上 `START-HERE.md` 的完整 Setup 提示詞。AI 先確認讀寫、命令與工具能力，再逐步帶領設定；後續用 `Setup` 續接。

`hi` 是普通問候，不保證四種模式都會自動啟動設定。Cowork／Work 的 hooks、CLI、技能發現與歷史對話能力，不能照搬 Code 的行為。帳號、OAuth、全域 hooks、排程與外部操作仍須由新使用者依需要授權。

需要確認視覺的報告、文件、網頁、軟體介面等成品，採「先做圖片 → 使用者選定視覺方向／版型 → 確認後實作」。圖片定案不取代實作後的功能、排版及響應式檢查。
