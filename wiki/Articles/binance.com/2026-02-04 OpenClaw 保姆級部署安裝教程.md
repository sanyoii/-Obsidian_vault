# OpenClaw 保姆級部署安裝教程

> **出處：** [binance.com](https://www.binance.com/zh-TC/square/post/36008200678113) | 0xMay | 2026-02-04

---

最近 OpenClaw 的熱度非常高，很多小夥伴都想第一時間上手體驗這款強大的 Ai 助理工具。表姐先幫大家踩踩坑，我分別在 Windows 和 MacBook 上進行了深度安裝測試。

一頓操作下來，最直觀的感受是：Windows 平臺的安裝體驗明顯更加友好。 相比之下，MacBook 的系統權限限制非常多，對於技術小白來說，調試過程極其折磨，稍有不慎就會卡在權限報錯上。所以如果想最快、最省心地用上 OpenClaw，Windows/Liux 是首選。

⚠️ 安全小貼士：在開始之前，有一個非常重要的提醒：由於此類工具涉及自動化操作和環境配置，如果你的電腦存有重要的商業/資產或個人隱私信息，強烈建議弄一臺乾淨的備用設備，或者直接租用一個雲端虛擬機（VPS）來運行。 這樣既能保護隱私，也能避免環境衝突。

**話不多說，教程正式開始 ！內容裏我會把自己遇到的問題和解決方式都寫出來，可能會有點長 ，安裝期間過程沒有報錯 跳過跳過就行 ！！**

## **第一部分：環境部署三部曲（打好地基）**

表姐寫的步驟都是按照 OpenClaw 能順暢運行的硬性要求寫的。如果環境不達標，後續安裝很容易報錯

**1/ 租虛擬機 （廣場不能放鏈接 自行搜教程）**  
**2/ 安裝官方正版的 nvm**

• 前往 github 下載 nvm-setup. exe 安裝後重新打開管理員模式的 PowerShell ( 鼠標右鍵 admin... )

![](https://public.bnbstatic.com/image/pgc/202602/322eb52bfa7f783a04b0b9d36a4bab88.jpg)

**3/ 安裝好後可以直接用 nvm 下載並使用 node.js 22.22.0 版本**

PowerShell 安裝&啓用指令 (分兩次進行) ：

nvm install 22

nvm use 22.22.0

![](https://public.bnbstatic.com/image/pgc/202602/aeae36bc3d29c2ed4bfecd9f1c2282e7.jpg)

⬆️⬆️ 顯示這個就是成功了

## **第二部分：開始安裝 OPENCLAW**

**Window Powershell 安裝指令 ：**

iwr -useb https://openclaw.ai/install.ps1 | iex

**⚠️ 出現以下報錯 說明你沒開管理員權權限**

解決方案 ：打開管理員 PowerShell 運行

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

![](https://public.bnbstatic.com/image/pgc/202602/80d4dc2f30275bfbcb2d81c218ab9624.jpg)

弄完之後再粘貼一遍安裝的代碼，應該就ok了。但是在這裏表姐又遇到了個新問題，意思大概就是我的電腦不知道它被安裝在哪裏了。沒有遇到問題的可以跳到下一部分。

![](https://public.bnbstatic.com/image/pgc/202602/0cfb70c66835d6553055ca20b264377b.jpg)

解決方法 ： 關閉並從新打開 powershell

運氣好的話 nvm 會自動處理路徑，如果沒自動處理好那就只能自己手動添加 。

手動添加方式 ：

1/ 運行以下指令確認 openclaw 所在位置

ls C:\\nodejs\\node\_global\\openclaw\*

![](https://public.bnbstatic.com/image/pgc/202602/876b95a6fc2ad2c11ec88952e9d10c2f.jpg)

然後 Window + S 搜索並打開 Environment Variables 點 New 自己手動添加，完事要點最下面的 OK 纔算添加成功。![](https://public.bnbstatic.com/image/pgc/202602/4f497ef6d2bc1ea10302c4b7557e61e8.jpg)

—————————————————

接着又關閉再從新打開 PowerShell Admin 版

在開始設置之前先提前決定好自己要用什麼 api （一會兒會需要填寫），根據喜好自行選擇ai模型 ：

![](https://public.bnbstatic.com/image/pgc/202602/158557d4e91023a14501f86305936677.jpg)

接下來正式開始設置 OPENCLAW

在 PowerShell 裏輸入 ：

clawdbot onboard --flow quickstart

第一個問題

I understand this is powerful and inherently risky. Continue? 選 Yes

然後就是按照步驟選擇模型

![](https://public.bnbstatic.com/image/pgc/202602/95ba5239d0f59ebc276a03b06e4ceee1.jpg)

最後用空格鍵選擇自己需要的功能就行啦，這些功能沒裝上後續可以在對話裏指揮bot給自己裝上![](https://public.bnbstatic.com/image/pgc/202602/0125c478c264320dedc43a4654a93664.jpg)

**然後到連接社交軟件環節**

我看了很多關於安全性的東西，感覺目前連接在whatsapp 和微信並不是非常安全的選擇，所以個人推薦還是給他連接一個 telegrambot 會更好其實

步驟也很簡單：去找 botfather 創建一個新的 bot 然後去 getidsbot 獲取自己 telegram 的數字賬號 id

![](https://public.bnbstatic.com/image/pgc/202602/9078393743d8aa0918d35ff28929bc7f.jpg)

![](https://public.bnbstatic.com/image/pgc/202602/6d05c9a20faf1f389118e46f1239313e.jpg)

兩個東西都拿到後我們繼續設置

Enter Telegram Bot Token ➡️ 粘貼 Botfather裏獲取的 API 回車鍵

然後 輸入 owner id/username 這裏直接填通過 getidsbot 獲取的數字 id

到這基本上就大功告成了 ，可以直接機器人發指令 /start

但是我在這又雙叒叕遇到了問題 😅 機器人沒反應

再回到 powershell 輸入指令 openclaw doctor

又排查了一下 顯示沒有安裝 Gateway

不知道哪一步錯了 但沒事 萬事皆可補救 ！

![](https://public.bnbstatic.com/image/pgc/202602/f3b8c64cca8483bd7f2b97ef61a30c46.jpg)

解決方法 ：

打開有管理員權限的 Powershell 運行：

openclaw gateway install

最後再運行啓動指令 ：

openclaw gateway start

然後就可以去跟機器人 /start 對話了

## **其他指令**

刷新/重啓機器人指令：

openclaw gateway restart

重置/更改 api 等配置細節指令：

openclaw config

機器人診斷：

openclaw doctor

機器人實時監聽器 ：

1. openclaw logs follow

(機器人卡 bug 在 powershell 裏會顯示 bug 原因)
