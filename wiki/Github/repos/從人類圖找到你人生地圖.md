## Description

從人類圖找到你人生地圖。單檔 Streamlit App，使用者輸入自己的人類圖類型/權威/通道/閘門 + 想問的問題（例：「我要月入30萬，該怎麼發揮天賦？」），程式從一份 ~2.3MB 的人類圖文獻知識庫中本地搜尋相關段落，交給 Gemini 2.0 Flash 整理成繁體中文的職涯財賦深度分析報告。

## 分析報告

### 這是什麼？

一個**極簡的 RAG 風格 Streamlit App**：把使用者的人類圖數據（類型/權威/通道/閘門）+ 一個職涯/財富問題，餵給「本地關鍵字搜尋 + Gemini 2.0 Flash」，產出繁體中文的客製化解讀報告。整個應用邏輯只有一個 189 行的 `Human Design.py`，沒有前端框架、沒有資料庫，靠 Streamlit 撐起 UI。

- Repo 大小僅 1162 KB，幾乎全部是 `knowledge_base.txt`（~2.3MB，repomix 判定為二進位已排除，未讀取內容）
- 作者：李晏駒（YG），版本 3.8（AI 繁體整理版）
- License：無
- 部署方式：GitHub Codespaces devcontainer，啟動即 `streamlit run`

### 核心機制

| 步驟 | 做法 |
|---|---|
| **知識庫** | `knowledge_base.txt` 以空行分段，`@st.cache_data` 快取讀取結果 |
| **本地搜尋** | `local_search()`：關鍵字（類型/權威/通道/閘門）逐段比對，命中即收錄，最多 15 段 |
| **AI 整理** | 段落 + 使用者數據 + 自訂問題 → `gemini-2.0-flash` → 結構化繁中報告（類型優勢/通道解讀/致富路徑） |
| **API Key** | 從 `st.secrets["GOOGLE_API_KEY"]` 或使用者輸入框取得 |

### 與其他人類圖收藏的比較

跟同一個 `wiki/Github/repos/` 資料夾裡的其他人類圖 repo 性質完全不同：

- [[Retsomm SelfMap 人類圖計算器 - Next.js + Swiss Ephemeris WASM|SelfMap]] / `lyts3333-droid/-human-design-calculator`：**計算引擎**，用 Swiss Ephemeris 從出生資料算出 Type/Profile/Authority/通道
- **這個 repo**：**不計算**，假設使用者已經知道自己的人類圖數據，純粹做「文獻檢索 + LLM 解讀」的應用層

兩者互補：前者解決「我的圖是什麼」，後者解決「這張圖對我的職涯/財富意味著什麼」。

### 值得參考的地方

- `local_search()` 的設計思路（本地關鍵字過濾 → 控制送進 LLM 的 context 量，避免 API 額度爆掉）是小型 RAG 應用的簡單可行模式，可參考用在其他「文獻庫 + LLM 解讀」場景
- 整個 App 對「人類圖計算」本身沒有任何邏輯，knowledge_base.txt 是否公開/品質如何決定了這個工具的實際價值，但該檔案未被收錄分析

### 注意事項

- 無 License，且核心資產（`knowledge_base.txt`，2.3MB 人類圖文獻）未納入此次分析（repomix 判定為二進位）
- 程式碼把 Gemini API Key 暴露在 UI 輸入框（雖然也支援 `st.secrets`），自行部署時注意金鑰管理
