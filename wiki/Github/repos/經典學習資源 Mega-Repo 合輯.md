### 1. build-your-own-x — 從零手刻技術學底層

**codecrafters-io/build-your-own-x** | ⭐ 520K | 無明確授權 | Markdown

收集「Build Your Own [技術]」教程的索引。涵蓋從零實作 Git、Redis、Docker、資料庫、區塊鏈、作業系統、程式語言、Web Server 等數十種技術。不只教你用工具，教你理解工具為什麼這樣設計。

**用途：** 想深入底層原理時的學習入口。Build Your Own Database / HTTP Server 對理解系統架構有幫助。

---

### 2. awesome — Awesome Lists 的總目錄

**sindresorhus/awesome** | ⭐ 480K | CC0 1.0

所有 Awesome Lists 的「meta-list」。每個 Awesome List 是某主題的精選資源清單，涵蓋程式語言、框架、工具、平台等。

**用途：** 發現新工具的入口。想了解某個技術領域有哪些好東西，從這裡開始搜。

---

### 3. freeCodeCamp — 全球最大開源教育平台

**freeCodeCamp/freeCodeCamp** | ⭐ 451K | BSD 3-Clause | TypeScript

免費互動式程式設計課程平台，涵蓋 HTML/CSS/JS、前端框架、後端 API、資料視覺化、資安、數學。通過後可取得免費認證。非營利組織運營。

**用途：** 補前端基礎或取得額外認證。唯一一個真正的程式碼專案（TypeScript + Node.js + React）。

---

### 4. public-apis — 免費公開 API 大全

**public-apis/public-apis** | ⭐ 445K | MIT | Python

按分類整理的免費公開 API 清單：天氣、金融、地圖、音樂、新聞、政府開放資料等。每個條目標注是否需 API Key、是否支援 HTTPS。

**用途：** 開發 side project 時快速找到可用 API。開發 job-crawler / social-monitor 等專案時的資源來源。

---

### 5. free-programming-books — 免費程式書籍大全

**EbookFoundation/free-programming-books** | ⭐ 391K | CC BY 4.0 | Python

多語言的免費程式設計書籍、課程、Podcast 資源清單。涵蓋幾乎所有程式語言和技術領域。有繁體中文分類。66K forks，GitHub forks 最多的 repo 之一。

**用途：** 學新技術時先來這裡找免費書。

---

### 6. coding-interview-university — CS 自學完整計畫

**jwasham/coding-interview-university** | ⭐ 354K | CC BY-SA 4.0

作者 John Washam 從 Web 開發者轉職 Amazon SDE 的完整自學筆記。涵蓋資料結構、演算法、系統設計、網路等 CS 核心知識。有繁體中文翻譯。最後推送 2025-08，內容已穩定。

**用途：** 非 CS 背景轉 SWE 的參考。系統設計和網路基礎部分即使走 QA 路線也有用。
