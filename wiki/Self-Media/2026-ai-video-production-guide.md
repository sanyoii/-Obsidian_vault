## 核心概念

這套工具不是單一方案，而是**三條路**對應**三類內容**。已驗證月收入三五萬、日產 30 條視頻、效率五倍提升。

### 三個工具是什麼

| 工具 | 性質 | 學習曲線 | 適用場景 |
|------|------|---------|--------|
| **Codex / Claude Code** | AI 程式員 | 無（純中文輸入） | 全流程自動化 |
| **Remotion** | 代碼框架 → 視頻 | 中（React 基礎） | 穩定栏目模板、批量渲染 |
| **HyperFrames** | HTML → 視頻 | 低（AI 生成 HTML） | 快速出片、知識卡片 |

**Codex vs Claude Code：** 功能相同（內置在 ChatGPT Pro vs Anthropic 訂閱），國內使用 Claude Code 相對穩定。

## 三條變現路線對比

### 路線 A：講書號 / 知識卡片 → 橱窗帶貨

**現實情況：** 目前抖音、視頻號賺到錢的講書號用的是 DeepSeek 寫文案 + 剪映出視頻，**不是 Codex + HyperFrames**。

**真實數據：**
- 視頻號書單號（22 天）：橱窗跟買 8,612 人次，佣金 6.4 萬元
- 抖音讀書賬號（20 天）：漲粉 11 萬，單篇最高 14 萬贊，月橱窗 1 萬+

**HyperFrames 能做嗎？** 可以，但沒額外優勢。效果和剪映相差無幾，但折騰成本高得多。

**變現方式：**
- 抖音 / 視頻號橱窗挂書鏈，佣金 10%-50%（圖書佣金率高但單價低）
- 0 粉絲也能開通視頻號橱窗

**法律提醒：** 總結觀點沒問題。大段朗讀原文算侵權，被投訴會下架。

✓ **門檻最低** | ✗ **變現速度慢** | ✗ **HyperFrames 無明顯優勢**

---

### 路線 B：帶貨視頻 / 混剪 → 電商變現

**核心邏輯：** 複刻爆款。用 FFmpeg 拆分爆款的關鍵幀 → 用 Codex 從素材庫自動配置視覺相似素材 → 自動配音 + 字幕 → 輸出剪映草稿 → 微調發布。

**工具鏈：** FFmpeg + Python + 豆包語音 API（配音 4-8 毛/條）*不用 Remotion / HyperFrames*

**門檻要求：**
- 需有自己的素材庫
- 能跑通 Python 環境
- 有電商內容經驗或想擴大產量

**真實產量：** 日產 30 條 = 原來 1 天 6 條，現在 30 條（五倍提升）

**變現最快** ✓ | **工具門檻最高** ✗ | **效率提升最明顯** ✓

---

### 路線 C：數據科普 / 知識圖表 → 算法驅動 + 品牌合作

**適用內容：** 全球最貴城市、過去 20 年收入變化、宇宙有多大、歷史人物的一生地圖展開…

**Remotion 的真正優勢：**
- 精準控制每一幀（毫秒級）
- 數字跳動、柱狀圖依次出現、高亮某項
- 數據更新後直接重渲染（不用重新剪輯）

**真實案例：**
- B 站「橙子科技崔子橙」（445 粉絲）：一條「歷史人物的一生展開成地圖」獲 87 萬播放 ← 典型算法推薦
- Manim 數學科普「Orthocenter」：37 萬粉絲，靠程序化幾何動畫

**為什麼剪映做不了：** 數據動畫、精準時間軸控制、動態更新需求 → 都是程式碼驅動

**適合發布平台：** B 站、視頻號（YouTube 中文版極少，英文數據可視化內容很稀缺）

**變現方式：**
- 播放量收益（B 站 10 萬播放 = 100-500 元）
- **品牌合作**（真正的變現口子）
- 課程銷售

✓ **差異化最大** | ✗ **變現最慢** | ✓ **內容稀缺算法喜歡**

## 最小起步：Codex + Remotion 第一條視頻

### Step 1：搭流水線（只做一次，10-20 分鐘）

打開 Claude Code，新建空文件夾，發這段話：

```
帮我用 Remotion + Edge TTS 搭一个"做中文配音视频"的项目。
横屏 1920×1080、视频长度跟着配音走、底部自动字幕、深色背景。
搭好渲染一个最小示例给我看效果。
```

Claude Code 會自己：
1. 裝 Node.js 依賴
2. 寫項目檔案
3. 渲染樣片給你看

之後你就有一套可反覆用的視頻模板。

### Step 2：每期視頻，兩步走

#### 第一步：要腳本（確認稿→再出片）

```
做一期关于【主题】的视频，面向【受众】，发【平台】，大概【时长】。
拆成 6-8 段，每段写口语化的口播文案 + 画面设计。
先给我看分镜脚本，我确认后再做。
```

**為什麼先看稿：** 文案是視頻的靈魂。稿子不對，後面白做。

#### 第二步：確認後，要視頻

```
按上面的脚本生成配音并渲染成 MP4。
```

十幾分鐘後，MP4 到手。

### Step 3：修改用大白話

不用懂參數，描述感覺就行：

```
第 3 段太長，精簡到一句話
換個活潑一點的年輕女聲
改成抖音豎屏 1080×1920，重新渲染
配色改暖色系
```

Claude Code 自己選具體設置。

## HyperFrames vs Remotion 詳細對比

### HyperFrames（HeyGen 出品，2026年 4 月開源，Apache 2.0 免費）

**工作流程：** 普通 HTML + CSS + GSAP 動畫 → Headless Chrome 逐幀截圖 → MP4

**核心優勢：** AI 會寫 HTML，Codex/Claude Code 幾乎不用學習就能上手

**安裝：**
```bash
npx skills add heygen-com/hyperframes --all
npx hyperframes preview   # 浏览器实时预览
npx hyperframes render    # 输出 MP4
```

**B 站參考：** 99+ 相關視頻，最高播放 27 萬（「hyperframes vs remotion 對比」）

### Remotion（2021 年，成熟工具）

**工作流程：** React 組件 → 幀數和時間軸控制 → MP4

**優勢：** 組件復用性強，批量渲染方案成熟，適合做品牌栏目、數據可視化、每週固定格式內容

**缺點：** AI 需先學會 Remotion API，生成代碼出錯率稍高

**官方支持：** 文檔頁加 `.md` 後綴獲取 Markdown 格式，Claude Code 可直接讀取

### 如何選

| 場景 | 選擇 |
|------|------|
| 快速出片，AI 直接生成 | HyperFrames |
| 穩定栏目模板，版本管理，長期維護 | Remotion |
| 有 React 技術背景 | Remotion |
| 完全不會編程 | HyperFrames |

## 實戰案例：用 Claude Code + HyperFrames 做 30 秒視頻

**總用時：** 60 分鐘（環境 20 分 + 寫代碼 30 分 + 渲染 10 分 + 踩坑處理 40 分）

### 環節 1：準備環境（20 分鐘）

```bash
# Node v26 有已知問題，切到 v22
source ~/.nvm/nvm.sh && nvm use 22

# 國內 npm 鏡像（否則裝包很慢）
npm config set registry https://registry.npmmirror.com
```

### 環節 2：讓 Claude Code 寫 HTML（30 分鐘）

新建文件夾，打開 Claude Code，需求說清楚：

```
30秒竖屏 1080×1920，深色背景，展示三步工作流。
最後一屏放群二维码。
```

Claude Code 生成完整 HTML + GSAP 動畫，包含 4 個場景：
- 大標題
- 步驟卡片
- 數據對比
- 結尾二維碼入場

所有入場動畫、進度條、底部署名 **全自動寫好**，無需改一行代碼。

### 環節 3：渲染（1 分 39 秒）

```bash
# render 接收目錄路徑，不接受檔案名
# 入口檔案必須叫 index.html
npx hyperframes render . --output demo-output.mp4
```

- 900 幀（30fps × 30 秒）
- 5 個 worker 並行
- 輸出 1.5MB 的 MP4

### 踩坑提醒

| 問題 | 原因 | 解法 |
|------|------|------|
| `Not a directory` 報錯 | render 接收目錄路徑，不接受檔案名 | 改成 `render .` |
| 找不到入口檔案 | 必須命名 `index.html` | 改檔案名 |
| 系統 Node v26 跑不動 | 已知兼容問題 | 手動切 v22 |

三個坑花掉 40 分鐘，實際邏輯用時只有幾分鐘。

## 帶貨視頻完整四步工作流

**前置條件：** 你已經有素材庫 + 有在跑的電商賬號

### Step 1：拆解參考視頻

發給 Codex：

```
帮我分析这个参考视频：work/reference.mp4
用 FFmpeg 拆分成逐镜头片段，提取每个镜头的关键帧截图，
同时把文案提取出来（用 ASR 转写），
生成 recipe.json，记录每个镜头的时长、场景类型和文案。
```

Codex 自己調用 FFmpeg，得到鏡頭結構表。

### Step 2：素材匹配

```
基於 recipe.json，遍歷我的素材庫 assets/，
給每個素材提取關鍵幀，按顏色/亮度/構圖和參考鏡頭做相似度匹配，
輸出 matches.json。
規則：同一素材不連續用，置信度低於 60% 標記為「缺素材，需人工補」。
寧可留空，也不要硬湊不搭的素材。
```

### Step 3：配音和字幕

```
素材確認後，生成配音：
讀取每段文案，用豆包語音 API 生成配音。
配音實際時長決定對應鏡頭時長——配音 5 秒，鏡頭拉到 5 秒。
字幕用詞級時間戳對齐，不要用字符數估算。
```

### Step 4：出剪映草稿

```
生成剪映草稿文件。
注意：三個 ID（內容 ID/元數據 ID/根索引 ID）必須一致且唯一，
素材路徑用絕對路徑，檔案必須真實存在。
```

第一次 20-30 分鐘，打開剪映檢查時間軸 / 字幕 / 配音同步。沒問題即可發布。

**效率提升驗證：** 原來 1 天 6 條 → 現在 30 條（五倍）

## 快速開始指南

### 選擇你的路線

**北京時間現在還有限制嗎？** 
- Codex（ChatGPT）：國內直接訪問有限制
- **Claude Code（Anthropic）：** 國內訪問相對穩定 ✓

### 路線 A：Remotion（適合長期做內容）

**前置設定：**
```bash
# 1. 切 npm 國內鏡像
npm config set registry https://registry.npmmirror.com

# 2. Node v22（v26 有 bug）
nvm use 22

# 3. 建立專案
npx create-video@latest --hello-world
cd my-video && npm install && npm run dev
```

**Remotion.config.ts 設定**（解決國內下載 Chrome Headless 超時）：
```typescript
import { Config } from '@remotion/cli/config';
Config.setBrowserExecutable(
  'C:\\Program Files\\Google\\Chrome\\Application\\chrome.exe'
  // Mac: '/Applications/Google Chrome.app/Contents/MacOS/Google Chrome'
);
```

**安裝 Remotion 知識包**（讓 Claude Code 學 API）：
```bash
npx skills add remotion-dev/skills
```

**第一次提示詞：**
```
我已經有一個 Remotion 項目，路徑是 [你的項目路徑]。
幫我做一個 60 秒的中文知識視頻，主題是【你選一個，如：時間管理的 3 個誤區】，
面向抖音 / 視頻號豎屏（1080×1920），加配音、底部自動字幕、深色背景。
先給我一個 6 段分鏡腳本，每段 10 秒，我確認後再用 npx remotion still 渲染單幀驗證。
```

**配音方案：**
- Edge TTS（免費）：Python 工具，`pip install edge-tts`，中文用 `zh-CN-XiaoxiaoNeural`
- MiniMax TTS API（更精準）：國內直連，字符級時間戳

### 路線 B：HyperFrames（快速出片）

**安裝與初始化：**
```bash
# 國內 npm 鏡像
npm config set registry https://registry.npmmirror.com

# 安裝 HyperFrames
npx skills add heygen-com/hyperframes --all
```

**第一次提示詞：**
```
幫我安裝 HyperFrames，然後做一個 60 秒豎屏視頻（1080×1920），
內容：介紹《[書名]》的 5 個核心觀點，面向抖音發佈。
風格：深色背景，每條觀點單獨一屏，文字逐字入場，結尾引導關注。
加中文配音（用 Edge TTS，聲音 zh-CN-XiaoxiaoNeural），加底部字幕。
先運行 npx skills add heygen-com/hyperframes --all 安裝工具後開始。
安裝依賴請用國內鏡像 https://registry.npmmirror.com
```

### 現實預期

**第一條視頻：** 1-4 小時（環境搭建 + 模板調試 + 第一次渲染）

**跑順後：** 單條視頻 ~10 分鐘（大部分時間在看結果、調字幕、確認配音語速）

發布前加上「AI 生成」標註：
