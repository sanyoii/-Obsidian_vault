AI

今天先介紹一個我覺得蠻有意思的小工具：Code Wiki。

它有點像是 Google 幫 open source repo 自動長出一份「可聊天、可導覽、還會帶架構圖」的 repo 說明書。

不是只幫你摘要 README 而已，而是直接把整個 codebase 變成一份可以查、可以問、可以一路點回原始碼的 wiki。這種方向我覺得對看陌生 repo 很有吸引力。
