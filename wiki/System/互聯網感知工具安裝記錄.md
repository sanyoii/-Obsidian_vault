### 已安裝但需要額外設定（⚠️）

#### YouTube（yt-dlp 已裝，PATH 未設）

**問題：** yt-dlp 安裝在 `%APPDATA%\Python\Python314\Scripts\` 但此路徑不在系統 PATH，agent-reach doctor 偵測不到。

**修復步驟（擇一）：**

方法 A — 永久加入 PATH（推薦）：
```powershell
# 在 PowerShell（管理員）執行一次
$scriptsPath = "$env:APPDATA\Python\Python314\Scripts"
$currentPath = [Environment]::GetEnvironmentVariable("PATH", "User")
if ($currentPath -notlike "*$scriptsPath*") {
    [Environment]::SetEnvironmentVariable("PATH", "$currentPath;$scriptsPath", "User")
    Write-Host "PATH 已更新，重新開啟終端後生效"
}
```

方法 B — 直接用絕對路徑：
```
%APPDATA%\Python\Python314\Scripts\yt-dlp.exe "https://youtube.com/..."
```

#### Reddit（rdt-cli 0.4.1 已裝，需登入）

**問題：** rdt-cli 已安裝（v0.4.1），但尚未執行 `rdt login`。

**修復步驟：**
```powershell
# 步驟 1：先在瀏覽器登入 Reddit（reddit.com）
# 步驟 2：
%APPDATA%\Python\Python314\Scripts\rdt.exe login
# 步驟 3：按提示操作（會開啟瀏覽器 OAuth 授權）
```

> **注意：** rdt-cli 0.4.2 在 PyPI 尚未發布（2026-06-06 確認），目前安裝的是 0.4.1，功能上無差異。

### 安裝失敗（❌ 需後續處理）

#### mcporter（語意搜尋 / Exa / 小紅書 / 抖音）

**問題：** `npm install -g mcporter` 執行時找不到執行檔（系統 npm 路徑問題）。

**影響頻道：** 全網語意搜尋（Exa）、微信公眾號、小紅書、抖音

**下次修復步驟：**
```powershell
# 步驟 1：確認 npm 路徑
where.exe npm
npm --version

# 步驟 2：安裝 mcporter
npm install -g mcporter

# 步驟 3：設定 Exa
mcporter config add exa https://mcp.exa.ai/mcp
# （Exa 有免費額度，可先試用）

# 步驟 4：驗證
agent-reach doctor
```

> 若 npm 指令找不到，先確認 Node.js 路徑是否在 PATH。上次安裝時 Node.js ✅ 已確認存在，問題在於呼叫 `npm` 時的工作目錄或 PATH 配置。
