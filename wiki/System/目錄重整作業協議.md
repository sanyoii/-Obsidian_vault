# 目錄重整作業協議

> 源自 2026-06-16 `d:\Claude` 重整任務的教訓。宣告「全面審計完成」後仍補漏了 3 個檔案，根因是審計靠手動分批掃描，沒有系統性 checklist。

## Step 0：移動前，先產生舊路徑清單

```powershell
# 範例：列出所有含舊路徑的檔案
$oldPaths = @("social-monitor","job-crawler","careerbot","hd-decode",
              "gbrain-skills","my-marketplace","brain-docs","Skill_origin")

Get-ChildItem -Recurse -Include *.md,*.ps1,*.sh,*.py,*.html,*.json `
  -Exclude node_modules | Select-String ($oldPaths -join '|') `
  | Select-Object Path,LineNumber,Line | Format-Table -AutoSize
```

**這份清單就是完成標準。** 移動後每一行都必須消失。

## Step Last：重跑同一腳本，確認輸出為空

不靠記憶、不靠感覺，輸出為空才能宣告完成。

## 三個踩坑教訓

### 1. 平行檔要同輪處理

`setup.ps1` 和 `setup.sh` 是平行檔，必須在同一輪一起對照更新。同理：`*.html` 和 `*.md` 放在同一個 grep 裡掃，不要分 session 補。

### 2. 移動前先確認目錄類型

```bash
# 區分 gitlink（mode 160000）vs 一般目錄（mode 040000）
git ls-tree HEAD <dir>
```

- **gitlink**（如 hd-decode、careerbot）：用 `Move-Item` + `git rm --cached <old>` + `git add active/<new>`
- **一般目錄**（如 job-crawler、social-monitor）：可直接 `git mv`
- **深路徑（node_modules）**：改用 `robocopy /E /MOVE /256`

### 3. 移動前先確認目錄是否乾淨

```bash
git status  # 確認無 untracked 意外檔案
ls <dir>    # 確認沒有意外嵌套目錄
```
