# 社群海巡 v2 設計文件

> 從 playwright 爬蟲改為 last30days 多平台研究引擎

## 背景

舊版（v1）用 playwright 抓取 X/Threads/IG，效果不穩定：
- Cookie 常過期、需定期重新登入
- Threads/IG 頁面結構改版就失效
- 只能抓到「當下出現的話題」，深度不足
- 沒有 Reddit、HN、Polymarket 資料

v2 改用 `last30days` skill 作為唯一資料來源：
- 搜尋你定義的**固定主題關鍵字**（watchlist）
- 跨 Reddit / HN / Polymarket / GitHub 取得社群真實聲量
- 不依賴 playwright，不需要管理 cookie

## 架構

```
Task Scheduler（10:30 / 22:00）
  └─ run.bat
      └─ d:\Claude\autohedge-env\Scripts\python.exe social_monitor_v2.py
          │
          ├─ 讀取 watchlist.txt（每行一個主題）
          │
          ├─ for each topic:
          │    uv run --project C:\Users\sanyo\.agents\skills\last30days
          │         python scripts/last30days.py "{topic}"
          │         --emit=compact --agent --depth=quick
          │
          ├─ AI 摘要（Gemini → Claude fallback）
          │
          ├─ reports/report-YYYY-MM-DD-HHMM.md（本機）
          └─ wiki/Social/社群海巡 YYYY-MM-DD-HHMM.md（Obsidian）
```

## 主題清單（watchlist）

路徑：`d:\Claude\active\social-monitor\watchlist.txt`

每行一個主題，`#` 開頭為注解。直接編輯此檔即可調整監控範圍，下次排程自動生效。

## 平台對照

| 面向 | v1（舊） | v2（新） |
|------|---------|---------|
| 抓取方式 | playwright 爬蟲 | last30days CLI |
| 資料來源 | X/Threads/IG | Reddit / HN / Polymarket / GitHub（免費無需 auth） |
| 觸發邏輯 | 被動：找當下熱門 | 主動：搜尋你定義的主題 |
| 穩定性 | 依賴 cookie + 頁面結構 | 依賴 API / RSS（較穩定） |
| AI 摘要 | 相同（Gemini → Claude） | 相同（Gemini → Claude） |
| 輸出格式 | 相同 | 相同 |

## 擴充 last30days 平台（可選）

需要 API key 才能解鎖的平台：

| 平台 | 環境變數 | 取得方式 |
|------|---------|---------|
| X/Twitter | `XAI_API_KEY` 或 `AUTH_TOKEN`+`CT0` | xAI API 或 X 帳號 cookie |
| YouTube | 無需 key（yt-dlp） | 安裝 yt-dlp 即可 |
| TikTok | `SCRAPECREATORS_API_KEY` | ScrapeCreators（100 free credits）|
| Instagram | `SCRAPECREATORS_API_KEY` | 同上 |

設定方式：將 key 加入 `d:\Claude\active\social-monitor\.env` 或 `~/.config/last30days/.env`
