# 投影片選擇系統

> 建立日期：2026-05-30（版型選擇器）；2026-05-30 更新（新增風格選擇器）

## 系統概覽

兩個 HTML 工具，說「做 slides」「做投影片」等關鍵詞時自動同時開啟：
- **版型選擇器**：瀏覽全部 71 套版型，篩選後複製版型名稱
- **風格選擇器**：三步驟 Wizard，從用途+氣氛推薦版型，並生成可用 Prompt

## 檔案位置

| 工具 | 路徑 | 說明 |
|------|------|------|
| 版型選擇器 | `d:\Claude\.claude\skills\slide-collection.html` | 71 套版型色塊一覽，點選複製名稱 |
| 風格選擇器 | `d:\Claude\.claude\skills\slide-style-selector.html` | 三步 Wizard：用途→氣氛→推薦+Prompt |
| Hook 腳本 | `d:\Claude\.claude\helpers\slide-collection-hook.cjs` | Node.js，同時開兩個頁面 |
| Settings | `d:\Claude\.claude\settings.json` | UserPromptSubmit hook，async: true |

## 風格選擇器（slide-style-selector.html）

三步驟 Wizard 流程：

**Step 1 — 用途**（6 個，擇一）
- 🚀 產品發表／Demo
- 📊 創業 Pitch
- 🎓 學術報告
- 📖 教學課程
- ✨ 社群內容
- 🏢 內部會議

**Step 2 — 氣氛**（7 個，可多選）
- ⚡ 科技感、◻ 簡約、📎 商務、🎨 設計師感、🌅 溫暖、📼 復古、🏮 中文美學

**Step 3 — 結果**
- 依用途×氣氛分數算法，顯示 top 6 推薦版型
- 設計系統建議：推薦字型組合（標題/內文）+ 版面節奏
- Prompt 生成器：點版型後自動生成可複製的 Claude 製作指令

### 設計系統建議對照

| 氣氛 | 字型組合 | 版面節奏 |
|------|---------|---------|
| 科技感 | Space Grotesk / JetBrains Mono | ≤2重點，大量留白，放代碼 |
| 簡約 | Inter / DM Sans | 1個核心訊息，圖文分離 |
| 商務 | IBM Plex Sans | 3-5 bullet，圖表為主 |
| 設計師感 | Playfair Display / Neue Haas | 不對稱構圖，視覺衝擊 |
| 溫暖 | Fraunces / Lora | 大量留白，暖色圖片 |
| 復古 | Barlow Condensed / Courier | 全版圖像，超大字型 |
| 中文美學 | Noto Serif TC / Noto Sans TC | 書法式留白，字間距放寬 |

## Hook 實作細節

```javascript
// slide-collection-hook.cjs（同時開兩個頁面）
const pattern = /slides|ppt|presentation|html.*slide|投影片|做簡報|簡報/i;
if (pattern.test(prompt)) {
    exec('start "" "...slide-collection.html"');
    setTimeout(() => exec('start "" "...slide-style-selector.html"'), 300);
}
```

- **async: true** — 非同步，不阻擋 Claude 回應
- **Node.js** — UTF-8 處理中文關鍵詞無問題
- **兩頁同開**：版型瀏覽器 + 風格 Wizard 各自獨立使用

## 版型選擇器功能（slide-collection.html）

- 四色色塊預覽（背景色、主強調色、次強調色、文字色）
- 篩選：全部(83) / html-ppt(36) / frontend-slides(34) / guizang(1) / html-anything(12) / 深色系 / 淺色系
- 點擊卡片 → 複製版型名稱到剪貼簿
- 右上角連結 → 跳轉到風格選擇器

## Hyperframes HTML 影片系統（2026-05-30 新增）

將 HTML 動畫組合渲染成 mp4，無需 Docker：

```bash
npx hyperframes init          # 建立新影片專案
npx hyperframes preview       # 瀏覽器即時預覽
npx hyperframes render        # 輸出 mp4（自動用 ffmpeg-static）
```
