# 區塊鏈與 Web3 QA 學習課程

這份課程從「一筆錢怎麼轉出去」開始，每章先理解 Web3 的原理，再用同一個案例練習 QA 怎麼測、怎麼判斷及留下證據。以 Python 基礎、尚未學 JavaScript 為起點，每週六小時作為學習預算。

2026-10-05 已完成全課程的章節設計及第一、二章學習包。第 3–20 章仍待製作；既有 Ch01 與 QA 筆記已列入取材對照，尚未逐章重製。完整的先備、QA 練習、來源去向與缺口見 [[wiki/Web3-基礎/區塊鏈與QA課程/06-Web3與QA課程設計|課程設計]]。

## 現在開始

[開啟第一週 HTML 學習包](第一週學習包.html)：在同一頁閱讀教材、練習與評分，解答預設收合。作答請另存自己的筆記，頁面不儲存答案。

教材修訂及驗證範圍見 [[wiki/Web3-基礎/區塊鏈與QA課程/04-第1週審查紀錄|第一週審查紀錄]]。

本次補上白皮書交易圖的逐步解說、讀圖與 QA 練習、六題驗收。後續章節沿 [[wiki/Web3-基礎/區塊鏈與QA課程/06-Web3與QA課程設計|來源與任務雙向核對方法]] 製作，作者負責對照來源；你完成必修只需讀學習包。第 3–20 章目前仍只有設計與來源核對要求。

第一章圖解已改成可讀的 SVG：交易交接總覽、單筆簽署與驗證細解、三節點時序、正常轉帳流程，均直接放在學習包相應段落。後續需要圖解時，作者沿課程設計的圖型選用與驗收方法處理。

先做 [[wiki/Web3-基礎/區塊鏈與QA課程/02-第1週作業|課前診斷]]，不查資料，保留不知道的答案。再讀 [[wiki/Web3-基礎/區塊鏈與QA課程/01-第1週教材|第 1 週教材]]，完成同一份作業。作答之後才打開 [[wiki/Web3-基礎/區塊鏈與QA課程/03-第1週解答|參考解答與評分]]。

這週做完後，把手算結果、Python 印出的內容、一份測試紀錄和課後題答案貼回目前對話。診斷原答也保留著；哪裡卡住，就在旁邊寫下來，批改時一起看。

## 章節安排

第一章核心觀念釐清後，開啟 [第二章學習包：Hash、簽章與錢包](第2章/第二章學習包.html)。它包含教材、兩張 SVG、Python 操作、固定簽章樣本、QA 判讀、新情境及包內補課。只需包內內容及 Python，沒有必讀外部文章；作者檢查見 [[wiki/Web3-基礎/區塊鏈與QA課程/第2章/04-審查紀錄|第二章審查紀錄]]。兩章均未有學員驗收結果。

## 每週怎麼學

每章包含案例解說、QA 示範、獨立操作、新情境驗收與包內補課。章節依能力分組，週次依實際時間安排；一章可以跨週。原約 120 小時／20 週保留作為暫定預算，先完成第一章再校正估時；延伸主題不擠進必修時間。範例的來源、版本與操作入口在製作該章時重查。

每四章檢查解釋、操作、陌生案例三項，任一核心觀念未過就補強。紀錄區分「獨立完成」「提示後完成」「參考答案後重做」，不把閱讀、AI 代做或看過答案當成已學會。可用 AI 詢問名詞，獨立驗收時先自行作答並揭露用過的提示。

第一章保留「第1週」檔名與 HTML 入口，接續既有筆記。教材可讀、程式可跑與學員掌握分開核對；學習者作答與學習成效尚未驗收。
