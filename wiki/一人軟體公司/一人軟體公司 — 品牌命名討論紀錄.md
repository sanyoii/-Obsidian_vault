# 一人軟體公司 — 品牌命名討論紀錄

> [!note] 結果
> 2026-11-21 定案：中文「編譯所」、英文「Compiled Works」，對外寫「編譯所軟體」「Compiled Works Software」。「一人軟體公司」留作內部代號。決定本身記在 [[一人軟體公司/一人軟體公司 — 規劃過程與決策紀錄]] 2.25；這頁記每一輪出過的名字、查證結果與被退回的理由。

## 1. 為什麼要另取名字

第 0 號案子是公司自己的官網。開工先定位（對象是未來的客戶，只放查證得到的內容），接著是名字。使用者補充了出售方式：公司要賣給很多人，買家設定完就上線、自己取名，所以品牌名是一個可以換的設定。使用者決定另取一個對外的品牌名。

## 2. 查證方法（每一輪都一樣）

- **網域**：用 RDAP 查註冊紀錄（`rdap.org`；`.com` 另向登記處 Verisign 直查）。每種結尾先用對照組驗過：已知有人用的網域回「已註冊」，亂數字串回「查無紀錄」。「查無紀錄」不保證買得到，價格沒查。
- **撞名**：中英文名稱各搜一次「名字＋工作室／設計／軟體」。搜尋工具偏美國結果，台灣的小工作室可能搜不到，所以只能說「沒看到」。
- **套件與帳號**：使用者自提的名字另查 GitHub 帳號、npm、PyPI 同名。
- **商標**：每一輪都沒查成。智慧財產局新版檢索網址是 `cloud.tipo.gov.tw/S282/S282WV1/`，從這台打開後公告視窗擋住查詢，請求沒有送出。

### 第 6 輪：六項條件，定案

使用者的條件：正式企業感、台灣自然語感、一語雙關、幽默深度、一聽就懂，並帶台灣獨立設計與文化品牌的文青留白、文字韻味與知性氣質。

做法：中文挑台灣日常用語裡剛好是軟體術語的詞，後面接「軟體」，英文接「Software」，讓後綴補上企業感與一聽就懂。網域加查 `.software`（對照組 `open.software`、`free.software` 回已註冊）。

| 中文（兩層意思） | 英文（兩層意思） | 網域 | 撞名 |
|---|---|---|---|
| **編譯所**（新聞的編譯；程式的編譯） | **Compiled Works**（作品全集；編譯完成） | `.software`、`compiledworkssoftware.com`、`.studio`、`.tw`、`.dev` 沒人註冊；裸 `.com` 已註冊 | 中英文都沒看到 |
| 好物件（好物、房仲的物件；物件導向） | Good Object | 同上，裸 `.com` 已註冊 | 沒看到 |
| 來函（公文來函；函式） | Return Value（回信；回傳值） | `.software`、`.studio`、`.tw` 沒人註冊 | 沒看到 |
| 斷句（古文斷句；解析） | Well Parsed | 除裸 `.com` 外都沒人註冊 | 台灣逗點人設計概念接近 |
| 行間（字裡行間；程式碼的行） | Linework（線稿；程式碼的行） | `.studio`、`.dev` 已註冊 | LINE 的企業版 LINE WORKS 念起來幾乎一樣（AI 的知識，這次沒另外查） |
| 造句（國小造句；用一句話造東西） | Statement | `.studio`、`.dev` 已註冊 | 紐約金融軟體公司 Statement |
| 初版（第一版的書；v1.0） | First Edition | `.studio`、`.dev` 已註冊 | 台灣「初版數位內容股份有限公司」（2023 成立） |
| 有解 | Solvent（財務健全；溶解問題） | `.studio`、`.dev` 已註冊 | 美國金融合規公司 Solvent |
| 常數（恆常；程式常數） | Constant | 全部已註冊 | 亞美尼亞 Constant Technologies |
| 索引 | Indexing | `.software` 沒人註冊 | 「索引軟體」是產品類別 |

AI 建議「編譯所 / Compiled Works」，第二是「好物件 / Good Object」。**使用者選編譯所 / Compiled Works。**
