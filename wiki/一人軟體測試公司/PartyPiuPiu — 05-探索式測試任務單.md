# 05-探索式測試任務單

文件版本：test-docs-v1.0｜依據：已核准企劃v0.2｜2026-09-17

> 本文件已編製，不代表產品測試通過。實際結果僅寫入原案件case.json並連到Run證據。

探索不是沒有邊界的隨便點選。以下六份charter合計210分鐘，包含在原工時內，與案例/重測共用資料配額；不是額外核准3.5小時或額外提交額度。未有環境與回復能力時只準備任務，不開始網站操作。

每次由一名執行者負責，主模型統整；真人與AI觀察分開標記。每10分鐘記一次實際動作/資料/發現，禁止以事後記憶填出不存在的證據。

## EXP-01｜新來賓第一次參加


| 欄位 | 內容 |
| --- | --- |
| 目標 | 新來賓第一次參加 |
| 探索重點 | 相機權限、冷載入與只留言入口 |
| 對應案例 | TC-07、08、09、13、29 |
| 時間上限 | 45分鐘 |
| 前提與邊界 | 先只讀與預覽，寫入依REC-04；兩台真機未取得則對應段落Not Run |
| 帶回成果 | 操作時間線、使用者卡點、疑似問題與證據、已探索及未探索範圍 |
| 停止條件 | 額度/時間到、環境異常、看到陌生資料或回復方式不明即停 |
| 目前狀態 | Not Run |

## 收尾與缺陷轉換

用五分鐘（計入各任務上限）整理：走過哪些路徑、哪個問題能重現、預期根據是哪一條、還缺什麼。新發現若超出既有案例，先追加案例定義並保留舊快照，規則確認後再Run。疑似問題留觀察，不為湊缺陷數直接寫產品Fail。正常觀察不等於所有相關案例自動Pass。
