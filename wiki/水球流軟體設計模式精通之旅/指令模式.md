## 核心定義

將每一道指令及其執行行為封裝成獨立的物件，藉此**解耦「操作」與「能力」**，並能輕易地實作「復原 (Undo)」與「重做 (Redo)」功能。

---

## 詳細說明

### 解決的 Forces

- 操作（呼叫方）不應直接依賴執行者（被呼叫方）的具體實作
- 需要支援操作歷史、Undo/Redo
- 操作需要排隊、延遲執行、或序列化

### 運作原理

```
Invoker（呼叫方）
  └── execute(command)

Command 介面
  ├── execute()
  └── undo()

ConcreteCommand（具體指令）
  ├── 持有 Receiver（真正執行者）
  ├── execute() → receiver.doAction()
  └── undo()    → receiver.undoAction()
```

### 關鍵能力：Undo/Redo

每個 Command 物件知道如何「執行」也知道如何「回滾」。
只需維護一個 Command 歷史堆疊，即可實現完整的 Undo/Redo 機制。

### 解耦的意義

「操作」（Invoker）完全不知道「能力」（Receiver）的存在，只透過 Command 介面互動。
新增能力只需新增 Command 類別，不修改 Invoker（OCP）。
