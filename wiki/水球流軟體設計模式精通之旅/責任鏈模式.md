## 核心定義

用於處理「**輸入比對型**」的行為變動，將多個處理者串聯成一條鏈，讓請求沿著鏈傳遞，直到被對應的處理者攔截並處理。

---

## 詳細說明

### 解決的 Forces

- 有多種條件/規則需要比對，而且規則的數量會擴充
- 每條規則對應不同的處理方式
- 規則的觸發條件是「輸入比對」型——根據輸入的特徵決定誰來處理

### 運作原理

```
請求 → Handler A → Handler B → Handler C → ...
        ↓（若符合）  ↓（若符合）   ↓（若符合）
       處理並停止    處理並停止    處理並停止
```

每個 Handler 決定：
1. 自己是否能處理此請求（比對條件）
2. 能處理就處理，不能就傳給下一個

### 與策略模式的關鍵區別（Forces 差異）

| | 策略模式 | 責任鏈模式 |
|---|---|---|
| Forces 類型 | 原始型行為變動 | 輸入比對型行為變動 |
| 選擇方式 | 外部指定策略 | 根據輸入自動路由 |
| 執行數量 | 一個策略 | 一個（或多個）handler |
| 典型場景 | 排序演算法切換 | 審批流程、過濾器鏈 |

課程以「Big 2（大老二）」實戰演練精準區分這兩個模式的 Forces 差異。
